你有没有想过，**当你看到一道闪光、听到一声巨响的那一刻，你的大脑里正在发生什么？**

几十年前，科学家把几十根金属电极贴在人的头皮上，成功"偷听"到了这些信号——那是大脑里数十亿个神经元齐刷刷放电时，泄漏到头皮表面的微弱电流。他们把这项技术叫做 **EEG（脑电图）**。

这一周，我第一次用 Python 打开了一份真实的 EEG 数据文件，从最基础的"这是什么格式？" 一路走到 "这些波形代表什么意思"。本文是这段旅程的完整白话记录。

🎯 本文适合谁？

对"脑机接口"充满好奇、但完全不懂信号处理的朋友。我会把所有技术术语翻译成你能看懂的人话。

<!--more-->

### 大脑是如何"说话"的？

我们先来搞清楚 EEG 到底在测什么。

想象你的大脑是一个体育场，里面坐着一千亿名观众（神经元）。当屏幕上出现一道闪光，靠近屏幕的观众会突然集体鼓掌——这个鼓掌声的震动传到体育场外，就是 EEG 能测到的信号。

传统 EEG 仪器

- 📡 头皮上贴几十根电极
- ⚡ 采集微弱电位变化（μV级）
- 🏥 医院常用于诊断癫痫
- 🔬 科研用于认知神经科学

我们用的数据

- 🎧 60个EEG电极
- ⏱ 每秒采样600次
- 👁️ 听觉 + 视觉双模态刺激
- 🐍 Python MNE 库处理

注意那个"每秒600次"——也就是说，这台仪器每隔 **0.00167秒** 就记录一次大脑的状态。录制4分半的数据，产生了将近 **10万个时间点** 的信号记录。

### 打开数据文件的第一反应："这是什么？"

用 Python 加载数据后，第一件事是看它的"基本信息"（就像查看一张照片的拍摄参数）：

{% asset_img 1.webp %}

这 376 个通道里，大部分是 MEG（脑磁图）传感器，真正的 EEG 电极只有 **60个**。我们这周专注于 EEG 部分。

{% asset_img 2.webp %}

把这些数字放一起理解：60个传感器，每秒各自采集600个数据点，录制了277秒……这份数据的体量是 **60 × 277 × 600 ≈ 996 万个数字**。这就是为什么需要专门的工具来处理它。

### 终于，我"看见"了脑电波

用 `raw.plot()` 一行代码，就能画出原始信号。下面这张图是前30秒里20个通道的样子：

📊 原始EEG信号图（前30秒，20通道）

{% asset_img 3.webp %}
<div align='center'>每条线代表一个电极，纵轴是电压（μV），横轴是时间（秒）。看起来像蚯蚓爬，其实都是大脑的活动轨迹。</div>

第一眼看到这张图时，我的感觉和你一样——**完全看不懂**。一堆乱七八糟的波形，不知道哪里是有用的信号，哪里是噪音。

但计算机帮我发现了一些问题：

**7个通道存在异常**：EEG 001、002、003、007、008、035、036 这几个电极的"峰峰值"超过了500μV（微伏）。 正常 EEG 信号通常在 10-100μV 范围内。这些异常可能来自 **电极接触不良**、**被试移动**，或者 **眼眨信号**。 在后续分析中，这些通道需要特别关注。

这就是为什么在处理 EEG 数据时，**第一步永远是检查数据质量**。就像医生照 X 光，先确认这张片子拍清楚了，再去看骨头。

### 大脑有自己的"音乐频段"

原始信号看起来复杂，但有个技巧：可以把它"分解"成不同频率的波——就像把白光通过棱镜分解成彩虹。

这个技术叫做 **PSD（功率谱密度）分析**，说白了就是："在这段脑电信号里，每种频率的振动有多强？"

📈 EEG功率谱密度分析图（Delta/Theta/Alpha/Beta/Gamma各频段）

{% asset_img 4.webp %}
<div align='center'>横轴是频率（Hz），纵轴是该频率的"能量强度"(dB)。颜色区域对应五个脑电频段。</div>

科学家把脑电分成了5个频段，每个都和不同的大脑状态有关：

{% asset_img 5.webp %}

**发现：Alpha 峰在 8.2 Hz**

分析结果显示，这份数据的 Alpha 频段峰值在 8.2 Hz。这是完全正常的——人类的 Alpha 峰通常在 8-12 Hz 之间，代表大脑在"待机状态"下的背景活动。 另外好消息是：**没有检测到明显的 50Hz 工频干扰**（那是插座里电流的频率，会污染信号）。

### 实验里的"关键帧"——事件标记

光看脑电波没什么意思，厉害的地方在于：这份数据里，**实验者同时记录了"什么时候给了被试什么刺激"**。

可以把它想象成一部电影的章节标记——在整段连续的录制里，打上了时间戳：

📋 本数据集的事件类型（共5种）

- **Auditory/Left** → 左耳听到声音（72次）
- **Auditory/Right** → 右耳听到声音（73次）
- **Visual/Left** → 左视野出现闪光（73次）
- **Visual/Right** → 右视野出现闪光（71次）
- **button** → 被试按下按键（15次）

🗂 事件分布图（Raster Plot）

{% asset_img 6.webp %}
<div align='center'>每一根竖线代表一次刺激发生的时刻。四种刺激均匀分布在277秒的录制时段里。</div>

有了这些时间戳，就可以做一件非常关键的事——**Epoch 切割**：把每次刺激前200毫秒到刺激后500毫秒的那段信号单独截取出来，研究大脑对刺激的反应。

🎬 类比：电影导演拍了一整天，剪辑时只保留"演员哭了"那30秒。Epoch 切割就是这样，从漫长的录制中，精准截取"大脑响应"的那一小段。

### 大脑的"条件反射"——ERP 分析

把同一种刺激对应的所有 Epoch 叠加平均，随机噪音互相抵消，真正的大脑响应就会浮现出来。这就叫 **ERP（事件相关电位）**。

我们用150μV的阈值过滤了质量太差的Epoch（就像相片拍糊了就删掉），最后保留了：

📊 Epoch 筛选结果

- **总切割数** 320 个 Epoch（4种条件各约80个）
- **被拒绝** 75 个（因为幅值超过150μV阈值）
- **有效保留 245 个**（约77%，质量相当不错）
- **时间窗口** 刺激前200ms → 刺激后500ms

📈 ERP Butterfly Plot（听觉 vs 视觉）

{% asset_img 7.webp %}
<div align='center'>每条细线是一个电极的响应，粗线是全部电极的平均值。蓝色=听觉刺激，红色=视觉刺激。刺激在 t=0 时发生。</div>

🧠 ERP 时间序列 — 中心通道（EEG 059）

{% asset_img 8.webp %}
<div align='center'>大脑在听到声音后约100ms出现一个负波（N100），这是大脑"收到刺激"的最早信号。</div>

看这张图里有两个标注窗口，这是 ERP 研究里最经典的两个"路标"：

🧭 ERP 经典成分

**N100（紫色区）**刺激后约80–150ms，出现负向波峰。代表大脑"察觉"到了刺激的最早信号。

**P300（橙色区）**刺激后约250–400ms，出现正向波峰。代表大脑对刺激进行了"更高级的认知处理"。

### 五天的旅程回顾

装好 Python 环境，第一次看到 EEG 数据的"说明书"（Info 对象）。376个通道、600Hz、.fif格式——全是陌生词汇，全部一一弄懂。

学会了用 `mne.find_events()` 找到实验的320个时间戳，并把它们对应的信号片段切割出来，准备好了分析的原材料。

把前四天串起来，从加载数据到生成 ERP 图，完成了人生第一个端到端的 EEG 分析流程，保存了6张分析图和1份文字报告。

### 这和 AI 有什么关系？

你可能想问：搞这些脑电分析，和 AI 有什么关联？

**EEG 数据本质上是时序信号**，跟语音识别里用到的声音信号、股票预测里用到的价格序列，属于同一类数据结构。处理它们用的数学工具（FFT、卷积、注意力机制）几乎相同。

{% asset_img 10.webp %}

脑机接口（BCI）做的事就是这条流水线：拿到脑电，提取特征，训练模型，最后让你"用意念控制"——操控轮椅、打字、甚至玩游戏。

这周完成的 ERP 分析，是这条流水线的第一步：**学会看懂大脑在说什么**。

### 01 统计分析

进行数据统计检验通常涉及三个主要步骤（如上图所示）：

- 检验数据是否遵循正态分布。
- 判断数据均值之间是否存在显著差异。
- 进行多重比较分析。

**论文实例：** Statistical analyses were performed using the software SPSS (Statistical Package for the Social Science, version 23, IBM). Using one-sample **Kolmogorov-Smirnov-tests**, we first verified that our variables followed a normal distribution to decide on **parametric** or **non-parametric statistics**. Accordingly, significant differences were evaluated using **repeated measures ANOVA** and **post hoc t-test** or **non-parametric Mann-Whitney U-test** (P ＜ 0.05). Based on this group classification, we subsequently used a **univariate ANOVA**, and **Kruskal-Wallis tests** to reveal **between-group differences**. Again, **t-tests** or **Mann-Whitney U-tests** were used post hoc [4].

#### 1 检验数据是否遵循正态分布

**Shapiro-Wilk检验**和**Kolmogorov-Smirnov检验**是常用的正态性检验方法。

- **Shapiro-Wilk检验（stats.shapiro）**：适用于小样本数据（通常样本量小于50）。A **Shapiro-Wilk** normality test was performed to test normality. ApEn and absolute band power estimates were **non-normal**; therefore, the **non-parametric Kruskal Wallis test** was applied for each band in EC and EO [6].
- **Kolmogorov-Smirnov检验（stats.kstest）**：适用于大样本数据。All time and frequency metrics were analyzed using the **Kolmogorov-Smirnov test** with the Lilliefors correction, **showing p<0.05. Consequently, the normality hypothesis is rejected**. The nonparametric technique to test whether the populations differ in location, the **Kruskal-Wallis H** statistic analysis does not require actualized observation values, the ranks of the observations to complete the analysis is known [7].

**python代码实现：**

```python
import scipy.stats as stats
import numpy as np

# 生成一些正态分布的数据
data = np.random.normal(loc=0, scale=1, size=100)

# Shapiro-Wilk检验
shapiro_test = stats.shapiro(data)
print(f"Shapiro-Wilk检验统计量: {shapiro_test[0]}, P值: {shapiro_test[1]}")
# 判断正态性
if shapiro_test[1] > 0.05:
    print("根据Shapiro-Wilk检验，数据符合正态分布。")
else:
    print("根据Shapiro-Wilk检验，数据不符合正态分布。")
```

```python
from scipy import stats
import numpy as np

# 生成不符合正态分布的数据
# 偏态分布（左偏）
group1 =  np.random.exponential(scale=1, size=50)

# 对数非正态
group2 = np.random.lognormal(mean=0, sigma=1, size=50) # np.random.laplace(loc=0, scale=1/np.sqrt(2), size=50)

# 偏态和峰态混合分布
group3 = np.append(np.random.normal(loc=5, scale=1, size=25),
                          np.random.normal(loc=15, scale=1, size=25))

'''Kolmogorov-Smirnov 检验'''
ks_results = {}
for i, group in enumerate([group1, group2, group3], start=1):
    stat, p_value = stats.kstest(group, 'norm')
    ks_results[f'Group {i}'] = (stat, p_value)
```

#### 2 判断数据均值之间是否存在显著差异

若各组数据服从正态分布并具备方差齐性，则适用**方差分析（ANOVA）**；否则可以考虑应用**Kruskal-Wallis H检验**，该检验为ANOVA的非参数替代方法。

方差分析（ANOVA）主要包括以下几种类型：

- **单因素ANOVA（One-Way ANOVA）（stats.f_oneway）**：用于比较两个或更多个独立样本组的均值，只有一个自变量，多个水平。 **One-way analysis of variance (ANOVA)** and χ2 tests were used to evaluate differences among the three groups on demographic, clinical and MoCA measures. The level of significance was set at α=0.05. If needed, data were transformed using natural log (LN) to approximate the normal distributional assumptions required by parametric statistical methods. Since there were group differences in age and education, these variables were included as covariates in subsequent analyses [9].
- **双因素ANOVA（Two-Way ANOVA）（stats.anova_lm）**：用于比较两个或更多个自变量对因变量的影响，可以同时考虑多个因素及其**交互作用。Two-way ANOVA** on the FD traits was performed during the first session of the ANOVA. In this analysis, the nonlinear features FD was the dependent variable, and the group factor (the individual MI-BCI performance from four classes (left hand, right hand, feet, and tongue)) among the eight subjects was the independent variable. All statistical tests had a significance level of p<0.05 [10].
- **重复测量ANOVA（Repeated Measures ANOVA）（stats.anova_lm）**：当同一组受试者在不同条件下接受多次测量时使用，用于比较同一受试者在不同时间点或条件下的均值。All ERP data were analyzed by a **3x3x2 repeated–measure ANOVA** with Group (F-MD, R-MD, and HC) as one betweensubjects factor, target expression (happy, neutral, and sad), and electrode location (P7 vs. P8 for N170) as within-subject factors [8].
- **混合设计ANOVA（Mixed ANOVA）**：结合了独立样本和重复测量设计，即有些自变量是独立的，而有些是在同一受试者内部重复测量的。The data for accuracy and RTs were analyzed by separate **3x3 ANOVAs** with Group (F-MD, R-MD, and HC) as one between-subjects factor, target expression (happy, neutral, and sad) as within-subject factors [8].
- **协方差分析（ANCOVA）（sm.OLS.from_formula）**：在ANOVA的基础上加入一个或多个协变量（连续变量），以控制这些变量对因变量的影响。All group analyses were conducted using **Analysis of Covariance (ANCOVA)** with the EEG measure as the dependent variable, group as the independent variable and age and education as the covariates [9].

**python代码实现：**

```python
from scipy import stats

# 假设有三个组的数据
group1 = [390,410,372,382]
group2 = [375,348,354,364,362]
group3 = [413,383,408]

# 单因素方差分析
f_value, p_value = stats.f_oneway(group1, group2, group3)
print(f"F-value: {f_value}, P-value: {p_value}")
```

还有另一种方法和更详细的内容，可以参考：https://blog.csdn.net/qq_45538220/article/details/134718877?spm=1001.2014.3001.5501

```python
import statsmodels.api as sm
from statsmodels.formula.api import ols
# 假设我们有以下数据，其中A（3个级别）和B（3个组别）是两个因子，Y是因变量
# 数据应该以Pandas DataFrame的形式组织
import pandas as pd
data = pd.DataFrame({
    'Y': [4, 6, 5, 15, 14, 14, 10, 13, 16, 7, 14, 11],
    'A': ['Level1', 'Level1', 'Level1', 'Level2', 'Level2', 'Level2', 'Level3', 'Level3', 'Level3', 'Level1', 'Level2', 'Level3'],
    'B': ['Group1', 'Group2', 'Group3', 'Group1', 'Group2', 'Group3', 'Group1', 'Group2', 'Group3', 'Group1', 'Group2', 'Group3']
})
# 使用ols模型进行拟合
model = ols('Y ~ C(A) + C(B) + C(A):C(B)', data=data).fit()
# 进行双因素和重复方差分析
anova_results = sm.stats.anova_lm(model, typ=2)
print(anova_results)
```

在这个例子中，C(A)和C(B)代表因子A和B的效应，C(A):C(B)代表A和B的交互效应。typ=2指定了使用II型平方和，这是当因子之间存在交互作用时常用的方法。anova_lm函数会输出一个方差分析表，其中包括每个因子的F值、自由度、平方和、均方以及p值，从而可以判断每个因子以及它们的交互作用是否对因变量有显著影响。

更多详细内容可以参考：https://blog.csdn.net/qq_45538220/article/details/134719298?spm=1001.2014.3001.5501

```python
# 例如：使用协方差分析（ANCOVA）来研究年龄作为协变量是否会对被试的EEG信号的P300幅值产生影响。
# ANCOVA能够帮助我们在控制年龄这一连续变量后，比较不同组别（例如不同实验条件或不同人群）在P300幅值上的差异。
import statsmodels.api as sm
import pandas as pd

data = pd.DataFrame({
    'Subject': [1, 2, 3, 4, 5, 6, 7, 8],
    'Age': [25, 30, 22, 35, 28, 40, 31, 29],
    'P300_Amplitude': [5, 6, 4, 7, 5, 8, 6, 7],
    'Condition': ['Control', 'Control', 'Experimental', 'Control', 'Experimental', 'Control', 'Experimental', 'Experimental']
})

# 将'Condition'转换为虚拟变量
data = pd.get_dummies(data, columns=['Condition'], drop_first=True)

# 协方差ANCOVA分析
# 'P300_Amplitude ~ Age + Condition_Experimental' 表示P300幅值与年龄和实验条件的关系
model = sm.OLS.from_formula('P300_Amplitude ~ Age + Condition_Experimental', data=data)

# 拟合模型
results = model.fit()

# 输出结果
print(results.summary())
```

#### 3 多重比较分析

如果ANOVA或KW检验结果显示显著性差异，可以使用多重比较方法（参数检验和非参数检验）来确定哪些具体组之间存在差异，一般情况下：

**组内：配对检验**
**组间：独立样本检验**

**t检验（参数检验）：样本应来自正态分布的总体。**

- **独立样本t检验（stats.ttest_ind）**：用于比较来自两个不同总体的样本均值之间的差异。 Accordingly, significant differences were evaluated using repeated measures ANOVA and **post hoc t-test** or non-parametric Mann-Whitney U-test (P ＜ 0.05) [4].
- **配对样本t检验（stats.ttest_rel）**：用于比较同一组对象在不同时间点或条件下的均值差异。The LSD (least significant difference) test was used for pair comparison, and the **paired T-test** was used for intragroup comparison [11].

**秩和检验（非参数检验）：它不依赖于数据正态分布的假设，适用于非正态分布的数据。**

- **独立样本Mann-Whitney U 检验（Mann-Whitney U test）(stats.mannwhitneyu)**:用于比较两个独立样本的中位数是否有显著差异。
- **配对检验 Wilcoxon 符号秩检验（Wilcoxon signed-rank test）(stats.wilcoxon)**:用于比较两个相关的样本或同一组样本在两个条件下的中位数是否有显著差。
- **论文实例**：Considering the small number of participants, all statistical analyses were conducted using non-parametric techniques. Differences in the demographic characteristics between left- and right-upper-limb paralytic (LULP and RULP, respectively) subjects were evaluated using the **Mann–Whitney U-test**. The differences in brain activity patterns between the left and right hemispheres were verified using the **Wilcoxon signed-rank sum test** [1].

**python代码实现：**

```python
import numpy as np
from scipy import stats

from statsmodels.stats.multicomp import MultiComparison
from scipy.stats import mannwhitneyu
# 生成不符合正态分布的数据
group1 =  np.random.exponential(scale=1, size=50)
group2 = np.random.lognormal(mean=0, sigma=1, size=50) # np.random.laplace(loc=0, scale=1/np.sqrt(2), size=50)
group3 = np.append(np.random.normal(loc=5, scale=1, size=25),
                          np.random.normal(loc=15, scale=1, size=25))
'''Kolmogorov-Smirnov 检验'''
ks_results = {}
for i, group in enumerate([group1, group2, group3], start=1):
    stat, p_value = stats.kstest(group, 'norm')
    ks_results[f'Group {i}'] = (stat, p_value)
''' Kruskal-Wallis H检验 '''
h_value, p_value = stats.kruskal(group1, group2, group3)
print(f"H-value: {h_value}, P-value: {p_value}")
''' mannwhitneyu 非参数检验'''
Tres = MultiComparison(data_melt['value'], data_melt['Treat']).allpairtest(testfunc = mannwhitneyu)
```

import scipy.stats as stats

# 示例数据
group1 = [20, 22, 19, 24, 23]
group2 = [21, 25, 17, 26, 18]

```

from scipy import stats

```

### 02 相关性分析

To assess how each of these transformations affected the outcome of the calculation of the correlation between SDS and FAA, **Spearman's rank order correlation (rho)** was applied to the association between the raw data for SDS score and each of the pairs of frontal EEG asymmetry values under eyes open and eyes closed conditions. **Because Spearman's rho is specifically designed to cater for the presence of non-normality, these results were used as the yardstick against which Pearson's r results could be compared when raw data and the logarithmic and RIN normalisation data were included.**[5]

#### 1 皮尔森相关

**皮尔森相关系数（Pearson Correlation Coefficient）**：是一种用于衡量两个变量之间线性关系强度和方向的统计量。它通常用来评估两个**连续变量**之间的相关性。
- **要求数据来自正态分布总体**。
- 变量之间的关系应该是线性的。
- 数据应该成对出现，即对于每个X值都有对应的Y值。
- **论文实例**：To explore the relationship between ERD% and fNIRS concentrations, amplitude and modulation correlations were conducted using **Pearson's r correlation**. Specifically, amplitude correlations were performed to investigate whether ERD% and fNIRS concentration changes correlate across individuals for ME and MI separately [2].

**python代码实现：**

```python
import scipy.stats as stats
# 示例数据
# 第一组数据
data1 = [1, 2, 3, 4, 5]
# 第二组数据
data2 = [5, 6, 7, 8, 7]
# 皮尔森相关系数分析
pearson_corr, pearson_p_value = stats.pearsonr(data1, data2)
print(f"皮尔森相关系数: {pearson_corr}, P值: {pearson_p_value}")
```

#### 2 斯皮尔曼等级相关

**斯皮尔曼等级相关系数（Spearman Rank Correlation Coefficient）**：斯皮尔曼等级相关系数是一种非参数统计量，用于衡量两个变量间单调关系的强度和方向。它通过比较两列变量的秩次（排序位置）来计算相关系数。

- **不要求数据来自特定的分布，但数据必须能够被排序**。
- 可以处理非线性关系的数据。
- 数据应成对出现，即对于每个X值都有对应的Y值。
- **论文实例**：To study the relation between the game time events and the EEG traits, we performed **Spearman's correlations** and reported the EEG traits with a strong (equal or higher than |0.5|) correlation's score and significant p-value (p < 0.005) [3].

**python代码实现：**

```python
import scipy.stats as stats

# 示例数据
# 第一组数据
data1 = [1, 2, 3, 4, 5]
# 第二组数据
data2 = [5, 6, 7, 8, 7]

# 斯皮尔曼等级相关系数分析
spearman_corr, spearman_p_value = stats.spearmanr(data1, data2)
print(f"斯皮尔曼等级相关系数: {spearman_corr}, P值: {spearman_p_value}")
```

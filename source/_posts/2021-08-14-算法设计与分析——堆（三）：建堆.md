我们可以用自底向上的方法利用过程`heapify(arr, i)`把一个大小为$n=A.length$的数组$A$转换为最大堆。子数组$A(\lfloor\frac{n}{2}\rfloor+1\cdots n)$中的元素都是树的叶结点。每个叶结点都可以看成只包含一个元素的堆。过程`max_heap(A)`对树中的其他结点都调用一次`heapify(arr, i)`：

<!--more-->

```python
def max_heap(A):
    for i in range(int(len(A) / 2), 0, -1):
        heapify(A, i)
```

为了证明`max_heap(A)`的正确性，我们使用如下的循环不变量：在第2-3行中每一次`for`循环的开始，结点$i+1, i+2, \cdots, n$都是一个最大堆的根结点。

我们需要证明这一不变量在第一次循环前为真，并且每次循环迭代都维持不变。当循环结束时，这一不变量可以用于证明正确性。

- 初始化：在第一次循环迭代之前，$i=\lfloor\frac{n}{2}\rfloor$，而$\lfloor\frac{n}{2}\rfloor + 1, \lfloor\frac{n}{2}\rfloor + 2, \cdots, n$都是叶结点，因而是平凡最大堆的根结点。
- 保持：为了看到每次迭代都维护这个循环不变量，注意到结点$i$的孩子结点的下标均比$i$大。所以根据循环不变量，它们都是最大堆的根。这也是调用`heapify(A, i)`使结点$i$成为一个最大堆的根的先决条件。而且，`heapify(A, i)`维护了结点$i+1, i+2, \cdots, n$都是最大堆的根结点的性质。在`for`循环中递减$i$的值，为下一次循环重新建立循环不变量。
- 终止：过程终止时，$i=0$。根据循环不变量，每个结点$1, 2, \cdots, n$都是一个最大堆的根。特别需要指出的是，结点1就是最大的那个堆的根结点。

我们可以用下面的方法简单地估算`max_heap(A)`运行时间的上界。每次调用`heapify(A, i)`的时间复杂度是$O(\log n)$，`max_heap(A)`需要$O(n)$次这样的调用。因此总的时间复杂度是$O(n\log n)$。当然，这个上界虽然正确，但不是渐近紧确的。我们还可以进一步得到一个更紧确的界。可以观察到，不同结点运行`heapify(A, i)`的时间与该结点的树高相关，而且大部分结点的高度都很小。因此，利用如下性质可以得到一个更紧确的界：包含$n$个元素的堆的高度为$\lfloor \lg n\rfloor$。所以我们可以得到`max_heap(A)`的时间复杂度为$O(n)$。

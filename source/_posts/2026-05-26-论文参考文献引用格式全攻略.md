最近参考文献格式这件事，有一个值得大家注意的新变化。

新版 **GB/T 7714—2025《信息与文献 参考文献著录规则》** 已经发布。国家标准全文公开系统显示，它的发布日期是 **2025 年 12 月 2 日**，正式实施日期是 **2026 年 7 月 1 日**，将代替大家更熟悉的 **GB/T 7714—2015**。

也就是说，接下来无论是写本科论文、硕士论文、博士论文，还是准备中文期刊投稿，参考文献格式都会逐渐进入一个“新旧标准衔接”的阶段。

所以这篇文章，我想做两件事。

第一，先把参考文献引用格式的基础知识讲清楚。比如正文里怎么标注，文末怎么著录， `[J]`、 `[D]`、 `[M]` 这些标识到底是什么意思。

第二，结合 GB/T 7714—2025，帮大家盘点一下这次新标准里更值得关注的变化。尤其是数据集、预印本、网站网页、永久标识符这类越来越常见的新型文献资源，到底应该怎么理解。

<!--more-->

说白了，这不是一篇让大家背规范的文章。

而是希望你下次写论文时，至少能**了解**：我这条参考文献属于什么类型，应该按哪套规则处理，什么时候该用学校模板，什么时候该看期刊投稿要求，什么时候可以交给工具做格式转换。

重要的是，当你知道这个规范以后，你才能更好的指挥你的AI帮你去做检查。当然，如果你不想学，可以让你的AI学。

### 先说一个最重要的原则：引用标注和文献著录不是一回事

参考文献不是“复制一段看起来像文献的文字”。

它至少包含两件事：

| 位置 | 你要做什么 | 常见形式 |
| --- | --- | --- |
| 正文里 | 告诉读者这句话、这个观点、这个数据来自哪篇文献 | `[1]`、 `[2-4]`、 `(Zhang, 2024)` |
| 文末参考文献表 | 给出完整文献信息，让读者能找到原文 | 作者、题名、文献类型、期刊/出版社、年份、卷期页码、DOI 等 |

也就是说，正文标注和文末列表必须能一一对应。

很多同学参考文献格式出问题，不是因为不会排版，而是因为一开始就没分清楚： **正文里是“引用标注”，文末是“参考文献著录”。**

### 国内论文常看的标准：GB/T 7714

国内论文最常见的参考依据，是《信息与文献 参考文献著录规则》。

简单说，如果你写的是国内毕业论文、课程论文、学位论文或中文期刊论文，GB/T 7714 通常都是绕不开的底层规范。

这里要提醒一句：如果你现在正在写毕业论文、课程论文或准备投稿， **不要只看国标名称，还要看学校模板和期刊投稿须知。**

因为实际写作中，学校和期刊经常会在 GB/T 7714 的基础上做更具体的要求，比如标点、英文作者大小写、是否必须写 DOI、是否要求中英文文献分开排列等。

### GB/T 7714—2025 主要变化怎么看？

从普通论文写作者的角度，不需要一上来逐条背标准原文。你先抓住一个方向就够了： **新标准更适应现在的学术传播环境。**

过去我们引用最多的是图书、期刊论文、学位论文、会议论文。但现在写论文时，经常还会遇到数据集、预印本、网页、在线报告、开放平台资源、带 DOI 或其他永久标识符的电子资源。

这也是 GB/T 7714—2025 比较值得关注的地方。

| 变化方向 | 怎么理解 | 写论文时要注意什么 |
| --- | --- | --- |
| 从“专著”到“图书” | 2025 版把相关表述调整为“图书”和“图书中的析出文献” | 不要机械背旧称，按学校模板和新标准语境理解 |
| 网站、网页单独规范 | 2025 版把网站、网页作为更明确的著录对象 | 引用网页时要保留发布/修改日期、引用日期、访问路径等信息 |
| 增加预印本 | 新标准增加了“预印本”及其标识代码 `PP` | arXiv、bioRxiv、medRxiv 等资源不能简单当作正式期刊论文 |
| 强化数据集 | 数据集有了更明确的著录位置 | 引用数据集时要写清数据集名称、发布平台、日期、访问路径或标识符 |
| 永久标识符更重要 | 2025 版使用“永久标识符”的表述 | DOI、Handle 等能帮助读者稳定定位原文，能保留就尽量保留 |
| 电子资源拆得更细 | 不再只是笼统写“电子文献” | 先判断它本质上是网页、报告、数据集、预印本，还是其他资源 |

这里要特别说明：新标准正式实施是 2026 年 7 月 1 日。如果你现在就要交论文，仍然要以学校今年发布的论文模板为准；如果你是期刊投稿，则以目标期刊的投稿规范为准。

### 参考文献里那些 `[J] [D] [M]` 到底是什么？

这些方括号里的字母，是文献类型标识。你可以先把它理解成“这条文献到底是什么东西”。

| 标识 | 文献类型 | 常见场景 | 最容易犯的错 |
| --- | --- | --- | --- |
| `[J]` | 期刊论文 | 中文核心、SCI、SSCI、普通期刊文章 | 漏掉卷、期、页码或 DOI |
| `[M]` | 专著/图书 | 学术著作、教材、译著 | 把学位论文误写成 `[M]` |
| `[D]` | 学位论文 | 本科论文、硕士论文、博士论文 | 不写保存单位，或误写成期刊 |
| `[C]` | 会议论文/会议录 | 学术会议论文集 | 分不清会议摘要和正式论文 |
| `[R]` | 报告 | 技术报告、研究报告、白皮书 | 不写发布机构 |
| `[N]` | 报纸文章 | 人民日报、光明日报等 | 缺少出版日期和版次 |
| `[S]` | 标准 | 国家标准、行业标准、ISO 标准 | 标准号和年份写不完整 |
| `[P]` | 专利 | 中国专利、美国专利、国际专利 | 不写专利号或公开日期 |
| `[EB/OL]` | 网络电子资源 | 网页、在线公告、机构页面 | 没有访问日期和链接 |
| `[DS]` | 数据集 | 开放数据、科研数据集 | 只写数据库名字，不写数据集题名 |
| `[PP]` | 预印本 | arXiv、bioRxiv、medRxiv 等 | 误当作已经正式发表的期刊论文 |

你真正要记住的不是所有字母，而是： **先判断文献类型，再套格式。**

如果类型判断错了，后面再怎么调整标点都救不回来。

### 期刊论文应该怎么写？

期刊论文是最常见的参考文献类型，一般用 `[J]`。

常见结构可以理解成：

| 信息块 | 作用 |
| --- | --- |
| 作者 | 谁写的 |
| 文章题名 | 文章叫什么 |
| `[J]` | 说明这是期刊论文 |
| 期刊名 | 发表在哪本期刊 |
| 年份、卷、期、页码 | 具体在哪一期、哪几页 |
| DOI | 电子定位信息，有就尽量保留 |

示意格式：

```
[序号] 作者. 文章题名[J]. 期刊名, 年, 卷(期): 起止页码. DOI.
```

中文示意：

```
[1] 张三, 李四, 王五. 某某机制研究[J]. 中国科学, 2024, 54(3): 123-132.
```

英文示意：

```
[2] ZHANG S, LI S, WANG W. Mechanism study of something[J]. Nature, 2024, 618(7965): 123-132. DOI: 10.xxxx/xxxxx.
```

这里最常见的错误有三个：第一，只写了期刊名和年份，没有卷期页码；第二，英文作者名字大小写和顺序混乱；第三，从网页复制时把数据库页面当成了论文信息。

### 本科论文、硕士论文、博士论文怎么写？

学位论文通常用 `[D]`。

不管是本科论文、硕士论文还是博士论文，在参考文献类型上都属于学位论文这一类。区别通常体现在题名、保存单位、年份，以及学校模板是否要求标注学位层级。

| 类型 | 文献标识 | 常见写法重点 |
| --- | --- | --- |
| 本科论文 | `[D]` | 看学校是否允许引用本科论文，注意保存单位 |
| 硕士论文 | `[D]` | 写清作者、题名、学校/保存单位、年份 |
| 博士论文 | `[D]` | 同样是 `[D]`，不是 `[M]` |

示意格式：

```
[序号] 作者. 论文题名[D]. 保存地: 保存单位, 年份.
```

示意：

```
[3] 李四. 某材料界面调控机制研究[D]. 北京: 清华大学, 2023.
```

很多同学会把硕博论文当成书来写成 `[M]`，这是非常典型的错误。

### 中文文献和英文文献，差别在哪里？

如果你是在国内论文里按 GB/T 7714 写参考文献，中文文献和英文文献可以放在同一个参考文献表里，但具体写法会有差异。

| 项目 | 中文文献 | 英文文献 |
| --- | --- | --- |
| 作者 | 通常写中文姓名 | 常见写法是姓在前、名缩写在后 |
| 题名 | 中文题名 | 英文题名，注意大小写规则 |
| 期刊名 | 中文期刊全名 | 英文期刊名，按要求全称或缩写 |
| 标点 | 常用中文论文模板规定的标点 | 可能更接近英文格式要求 |
| 排列 | 顺序编码制常按正文出现顺序 | 著者-出版年制可能按作者字母排序 |

所以，不要看到英文文献就慌。

关键还是先判断：这篇是不是期刊论文？是不是会议论文？是不是学位论文？然后再按照目标模板处理作者、题名、期刊名和卷期页码。

### 投海外期刊，标准是不是不一样？

是的，很多海外期刊并不使用 GB/T 7714。

如果你投英文期刊，第一件事不是问“国内格式怎么写”，而是看目标期刊官网的 **Author Guidelines** 或 **Instructions for Authors**。

| 常见格式 | 常见使用场景 | 特点 |
| --- | --- | --- |
| APA | 心理学、教育学、社会科学 | 作者-年份制常见 |
| MLA | 人文学科 | 重视作者和文本来源 |
| Chicago | 历史、人文、部分社科 | 有注释-书目制和作者-年份制 |
| Vancouver | 医学、生物医学 | 数字顺序编码常见 |
| IEEE | 工程、计算机、电气电子 | 数字编号制常见 |
| AMA | 医学相关领域 | 医学期刊常见 |
| Nature style | Nature 系列及相近科技期刊 | 按期刊要求执行 |

最稳妥的做法是： **目标期刊要求什么格式，就转成什么格式。**

同一篇论文，在中文毕业论文里可能要转成 GB/T 7714；投医学英文期刊时可能要转成 Vancouver；投心理学期刊时可能要转成 APA。

### 引用格式转换到底什么时候用？

很多同学看到“引用格式转换”工具，会以为它只是把标点改一改。

其实它真正适合这些场景：

| 输入内容 | 适合做什么 | 输出场景 |
| --- | --- | --- |
| DOI | 自动补全论文题名、作者、期刊等元数据 | 转 GB/T 7714、APA、Vancouver 等 |
| BibTeX | 从 LaTeX、Google Scholar、数据库导出的引用数据 | 转成 Word 论文需要的参考文献 |
| RIS | Zotero、EndNote、Mendeley 常用交换格式 | 在不同文献管理工具之间迁移 |
| 普通引用文本 | 你手里已有一条不规范参考文献 | 检查并改成目标格式 |

**但这里一定要注意：格式转换工具不能替你证明一篇文献真实存在。**

**如果原始信息是错的，比如作者错了、题名错了、DOI 不存在，工具最多只能把错误排得更整齐。**

### 这几个 AI 提示词可以直接用

如果你想让 AI 帮你检查参考文献，最好不要只说“帮我改一下格式”。

你要把任务说得更清楚，尤其要强调： **不要编造缺失信息。**

| 使用场景 | 推荐提示词 |
| --- | --- |
| 转成 GB/T 7714 | `请将下面参考文献整理为 GB/T 7714—2025 风格。请先判断每条文献类型，如 [J] [D] [M] [S] [EB/OL]。只能使用我提供的信息，不要编造 DOI、页码、卷号、期号或作者。缺失字段请用“需核查”标出。` |
| 检查格式错误 | `请检查下面参考文献是否存在格式问题，用表格列出：序号、文献类型、主要问题、建议修改。不要重写全文，只指出需要核查和修改的地方。` |
| 学位论文专项检查 | `请检查下面参考文献中是否有学位论文被误写成专著或期刊论文。请识别本科论文、硕士论文、博士论文，并统一按学位论文 [D] 的思路给出修改建议。` |
| 转成海外期刊格式 | `请将下面参考文献转换为目标期刊要求的 Vancouver 格式。请保留原始文献信息，不要添加不存在的字段。转换后列出仍需人工核对的字段。` |

AI 很适合做格式检查、类型判断、缺失字段提醒。

但论文引用有一个底线： **文献真实性必须由真实数据库、真实 DOI、真实原文来支撑。**

### 最容易被忽略的 7 个坑

| 坑 | 为什么危险 | 怎么避免 |
| --- | --- | --- |
| 正文编号和文末编号对不上 | 读者找不到来源 | 写完后统一交叉检查 |
| 学位论文写成 `[M]` | 文献类型错误 | 学位论文统一先按 `[D]` 判断 |
| 只复制网页标题 | 缺少真实出版信息 | 回到论文原始页面或数据库核对 |
| 英文作者顺序混乱 | 海外格式尤其容易错 | 按目标格式统一处理 |
| 漏掉卷、期、页码 | 期刊论文信息不完整 | DOI、期刊官网、数据库三方核对 |
| 网页没有访问日期 | 在线资源不可追溯 | `[EB/OL]` 类型补访问日期和链接 |
| 让 AI 编 DOI | 可能生成假文献 | 明确提示“缺失就标注需核查” |

参考文献这件事，看起来是格式问题，本质上其实是学术可追溯性问题。

你的读者、导师、审稿人看到一条参考文献，应该能顺着它找到真实来源。

### 最后推荐几个工具场景

如果你全流程用了Zotero这样的知识库管理软件，是可以直接导出引用论文格式的。如果你手动复制粘贴的，请注意一下格式。可以通过提示词的方式，让AI给你检查，也可以借助一些工具。

**第一类：文献真实性核查。**

这类场景最怕的是 AI 幻觉。比如 AI 给你生成一条看起来很完整的文献，作者、题目、期刊、卷期页码都有，但真实数据库里根本查不到。

所以涉及文献真实性时，可以用 Citely.ai 做核查：确认这篇文献是否真实存在，题名、作者、DOI、期刊信息是否能对应上。尤其是当你手里有一批 AI 生成或别人整理的参考文献时，先核查真实性，比直接排版更重要。

**第二类：引用格式转换。**

如果你已经有真实文献，但格式乱七八糟，就适合用 Literfy.ai 的文献格式转换能力。免费的积分可以转换几十条文献，应该可以够硕士论文使用了。

比如你可以输入 DOI、BibTeX、RIS，或者一段普通引用文本，然后选择输出为 GB/T 7714、APA、Vancouver 等目标格式。

这类工具的价值不是替你“编文献”，而是帮你把真实文献信息转成不同论文场景需要的样子。

### 写在最后

我对参考文献格式的理解是，他有点儿像是论文的门面。我在看论文的时候，我经常翻到最后一部分，一方面看看文献是不是核心期刊，整个论文作者是不是在高质量的参考论文基础上完成的自己的研究。另一方面，我会看文献的格式，它一定是最能暴露学术习惯的部分。

写得规范，说明你的研究是可追溯的；写得混乱，哪怕正文再漂亮，也会给人一种不够严谨的感觉。

从一开始就把文献真实性、引用标注和格式转换放进工作流里，后面改论文、投期刊、换模板，都会轻松很多。

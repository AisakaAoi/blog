用AI之前和用AI之后，我找文献、读文献的方法，几乎完全不一样了。

我自己评估下来， **用AI检索和阅读文献，效率比以前提升了十几倍。**

回想以前，最卡我时间的地方主要有两个。

**第一个，是检索文献。** 检索英文文献的时候，我需要不断地把中文关键词翻译成英文，还要换着不同的说法反复搜。而且要用好几个数据库：先在国内的数据库里检索中文论文，再去国外的数据库检索英文论文。一圈下来，时间就过去了大半。

**第二个，是翻译论文。** 英文论文我读得比较慢。在有AI之前，我用得最多的翻译工具是DeepL，一段一段复制过去翻译，再回到原文对照着看。

现在有了AI以后，我发现无论是文献检索，还是文献阅读，速度都有了非常大的提升。

先给大家看看我工作的「硬件」。用了扩展屏以后，感觉看文献舒服很多，左侧是英文原文、中间是翻译的中文、再右侧是可以聊天的 AI。如果 AI 干活儿慢了，我可以低头用笔记本干其它活儿。

{% asset_img 1.webp %}

展示完我的「硬件」后，下来分享我的AI 辅助下的工作流程。

<!--more-->

### 01｜第一步：一句话检索近5年的中英文文献

打开YILA的主页，在输入框下方选择“Literature Search”（文献搜索），然后在输入框里输入你要检索的内容。

{% asset_img 2.webp %}

我个人的习惯是，一般会要求检索 **最近5年的中英文文献。** 比如：

```
帮我检索近5年媒体融合传播效果评估的中英文文献。
```

剩下的，就交给AI去帮我检索。中文和英文文献会一起检索出来，我不需要再自己翻译关键词，也不需要在多个数据库之间来回切换。在这个部分，我发现 Agent 已经很聪明了，检索的时候「说人话」就好。

我最近观察，很多 00 后的研究生，他们使用 Agent 的时候，输入非常「大胆」。完全把 Agent 当人在用。我在刚开始用 Agent 的时候，有一阶段，担心输入不准确，AI 不能很好的理解我。后来发现不是这样的。Agent 可以很好的理解语义，然后拆解关键词，去检索。

如果拿到结果以后，觉得论文还不够，可以直接继续追问。比如：

```
英文文献偏少，请换用其他常见的英文表达，再补充检索一轮。
```

```
请按“评价指标构建”“效果测量实证”“平台案例”三个方向，分别补充检索。
```

用聊天的方式一轮一轮补充，我觉得还是挺方便的。

{% asset_img 3.webp %}

右侧是检索到的文献列表。可以直接下载 Excel。

### 02｜第二步：看论文矩阵，确定要精读哪几篇

检索完成以后，就进入文献阅读的环节。

在用AI之前，我会自己手动做很多Excel表格：梳理有哪些论文，每篇论文的摘要是什么，和我的题目有没有关系。光是整理这张表，就要花不少时间。

**现在，AI会自动帮我整理好。**右侧的Paper results面板，会把每篇论文的摘要、和我研究主题的相关性都梳理出来，还标注了CSSCI、核心期刊、EI等期刊标签。

{% asset_img 4.webp %}

英文论文也在同一张表里：

{% asset_img 5.webp %}

这样看起来就方便多了。可以很快了解这个方向上目前主要有哪些论文，大家在研究什么。

**也是在这个阶段，我会确定要重点精读的论文。** 我一般会结合相关性和期刊级别，挑出5篇左右精读。（建议在论文充足的情况先，看核心期刊论文就好了。）

### 03｜第三步：检索到的论文，直接在线阅读、和论文聊天

确定了要精读的论文以后，主要看一下论文旁边的 **“开锁”标识。** 带有这个标识的论文，表示可以直接下载，也可以在线阅读原文。

{% asset_img 6.webp %}

点击PDF，就可以在右侧直接打开原文阅读。（不需要校园 VPN，就可以看到知网和万方的论文，也能下载。）：

{% asset_img 7.webp %}

打开论文以后，还可以点击右上角的“Chat with Yila”。这篇论文会作为附件出现在对话框里，大模型会直接阅读这篇论文的原文，我可以直接向它提问，了解这篇论文的研究问题、方法、结论和局限。

**整个过程都在YILA里完成，不需要跳转到任何其他网站。**

{% asset_img 8.webp %}

（这张图来自我另一次检索慢性肾病发病机制文献时的截图，操作方式是一样的。）

### 04｜第四步：手上已有的论文，用Chat with PDF

如果你手上已经有从其他平台下载的论文，也可以用YILA的Chat with PDF功能。点击左侧的Chat with PDF，上传论文就可以开始。

{% asset_img 9.webp %}

上传以后，页面会同时展示三部分内容：左边是论文原文，中间是翻译好的中文，最右边是对话框。（这个是我现在最喜欢的一个功能，看大屏通过聊天的方式看论文！！）

这里给大家一个小建议： **读论文的时候，尽量用大一点的屏幕。**

我自己一般会接一块扩展屏。这样论文原文、翻译后的论文和对话框可以同时铺开，一眼就能看到好几个维度的信息。读到某个地方不明白，不用切换窗口，直接在最右侧提问就行。遇到看不懂的公式和表格，还可以点击“Explain math & table”，让它单独解释。

以前用DeepL，需要一段一段复制过去翻译，再回到原文对照着看。现在原文、翻译和提问都在同一块屏幕上，读论文的效率提高了很多。

下面这张图，我用的是一篇大家比较熟悉的经典论文《Attention Is All You Need》：

{% asset_img 10.webp %}

读论文时，可以试试下面这几个问题：

```
1. 这篇论文要解决的研究问题是什么？
2. 它用了什么研究方法和数据？
3. 它的核心结论是什么？支撑结论的证据在论文的哪一部分？
4. 这篇论文有哪些局限？作者提出了哪些未来研究方向？
5. 这篇论文对我的研究主题【填写你的主题】有什么启发？
```

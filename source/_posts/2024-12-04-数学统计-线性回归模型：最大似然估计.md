### 1 似然估计

**似然估计（Likelihood Estimation）**是一种**统计方法**，指的是**通过观察到的数据来推测模型参数**。这是很简洁的一句话，但是感觉又不是很理解，下面我们对这句话进行一个更详细的解释：

- **统计方法：**
  - 某种模型或假设。如伯努利分布、正态分布等。
- **观察数据：**
  - 我们从实验、调查或其他来源**收集到的实际结果**。
- **模型参数：**
  - 在统计分析中，我们通常希望了解**某个过程或现象的背后规律**（如观测到的数据的背后的规律），这些规律通过模型的参数来表示。
- 推断模型参数：
  - 我们希望用这些数据来确定模型中的参数是什么，比如说某个统计分布的概率、均值或方差等
- **常见的统计模型**及其参数示例：
  - **线性回归模型**：
    - 参数：**截距 β0** 和**斜率 β1**。
    - 目标：通过观测数据（自变量和因变量）来估计这些参数，以描述自变量与因变量之间的关系。
  - **正态分布**：
    - 参数：**均值 μ** 和**方差 σ²**。
    - 目标：通过观测数据计算样本均值和样本方差，从而估计总体的均值和方差。
  - **逻辑回归模型**：
    - 参数：**回归系数 β**。
    - 目标：通过观测数据估计这些系数，以预测事件发生的概率。

总的来说，似然估计是一种使用实际数据来估计模型参数的方法，即**通过观察数据，寻找最有可能导致我们观察到这些数据的参数值**。

### 2 最大似然估计

**最大似然估计（Maximum Likelihood Estimation, MLE）**是似然估计的一种特定方法，目的是**找到使得似然函数取得最大值的参数。**

MLE 通过**最大化似然函数（或对数似然函数）来估计模型参数，**使得在给定这些参数的情况下，观察到的样本数据的可能性最大。

这里需要注意**似然函数**与**概率**的区别：
- **概率**：**概率是描述某一事件发生的可能性的数值**。它通常表示为介于0和1之间的一个数，其中0表示事件不可能发生，1表示事件一定会发生。概率是基于已知的参数或条件来预测未来的事件。
- **似然函数**：**似然函数描述的是在不同参数值下，观察数据出现的可能性**。

**例子：投掷硬币**（来自AI）

**1. 观测数据**

假设你投掷了一枚硬币 10 次，得到的结果是：

- 正面（H）：7 次
- 反面（T）：3 次

**2. 模型假设和参数估计**

我们假设这枚硬币是一个**伯努利分布**的随机变量。我们**希望估计参数 p**，用来表示硬币朝上的概率（即投掷得到正面的概率）。在这个模型中：

- p：正面出现的概率
- 1−p：反面出现的概率

**3. 似然函数**

根据观测数据，我们可以构建似然函数。**对于这个例子，似然函数 L(p) 表示在参数 p 下观测到 7 次正面和 3 次反面的可能性**：

$$L(p) = P(7\ H, 3\ T\ |\ p) = \binom{10}{7} p^7 (1-p)^3$$

其中：

- $\binom{10}{7}$ 是组合数，表示从 10 次投掷中选择 7 次正面的方式数。
- $p^7$ 是正面出现 7 次的概率。
- $(1-p)^3$ 是反面出现 3 次的概率。

**4. 最大化似然函数**

为了找到最佳的 p，我们可以**最大化这个似然函数**。通常，我们会使用对数似然函数：（在这里：**当你最大化似然函数时，你实际上是在寻找一个最佳的 p 值，使得观察到的数据在该 p 下的可能性最大**。）

$$\log L(p) = \log \binom{10}{7} + 7\log(p) + 3\log(1-p)$$

接下来，我们对 $\log L(p)$ 取导数并设为零，来找到使得似然函数最大的 $p$。

我们现在对 $\log L(p)$ 关于 $p$ 进行求导：

$$\frac{d}{dp}\log L(p) = \frac{7}{p} - \frac{3}{1-p}$$

这里的每一项解释如下：

- $\frac{7}{p}$ 是正面出现的部分，表示概率 $p$ 增加时，正面数对似然的贡献。
- $\frac{3}{1-p}$ 是反面出现的部分，表示概率 $1-p$ 增加时，反面数对似然的贡献。

**5. 求解模型参数**

为了找到最大似然估计，我们将导数设为零：

$$\frac{7}{p} - \frac{3}{1-p} = 0$$

接下来，我们解这个方程：

1. 将方程两边乘以 $p(1-p)$ 以消除分母：

$$7(1-p) = 3p$$

2. 展开并整理：

$$7 - 7p = 3p$$

$$7 = 10p$$

3. 解出 $p$：

$$p = \frac{7}{10} = 0.7$$

**6. 似然函数值**

接下来，我们计算在 $p = 0.7$ 下的似然函数值 $L(0.7)$：

$$L(0.7) = \binom{10}{7}(0.7)^7(0.3)^3$$

我们已经知道组合数和概率的计算步骤，其中 $\binom{10}{7} = 120$，因此：

$$L(0.7) = 120 \times (0.7)^7 \times (0.3)^3 \approx 0.267$$

上述结果表明：**似然函数 L(0.7) ≈ 0.267 为在参数 p = 0.7 下，观测到硬币 7 次正面和 3 次反面的可能性。**

**例子：正态分布的情况**（来自AI）

**1. 模型假设和参数估计**

假设我们的观测数据 $x_1, x_2, \ldots, x_n$ 服从正态分布 $N(\mu, \sigma^2)$，我们希望估计均值 $\mu$ 和方差 $\sigma^2$。

- 似然函数：

$$L(\mu, \sigma^2\ |\ x) = \prod_{i=1}^{n}\frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x_i - \mu)^2}{2\sigma^2}\right)$$

- 对数似然函数：

$$\log L(\mu, \sigma^2\ |\ x) = -\frac{n}{2}\log(2\pi) - \frac{n}{2}\log(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(x_i - \mu)^2$$

**2. 最大化对数似然**

我们对 $\mu$ 和 $\sigma^2$ 分别求偏导数并设为零：

- 对 $\mu$ 求导：

$$\frac{\partial}{\partial\mu}\log L = \frac{1}{\sigma^2}\sum_{i=1}^{n}(x_i - \mu) = 0$$

解得：

$$\hat{\mu} = \frac{1}{n}\sum_{i=1}^{n}x_i$$

- 对 $\sigma^2$ 求导：

$$\frac{\partial}{\partial\sigma^2}\log L = -\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2}\sum_{i=1}^{n}(x_i - \mu)^2 = 0$$

解得：

$$\hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \hat{\mu})^2$$

### 3 线性回归模型中的MLE

**线性回归模型**

在**线性回归（Linear Regression，RE）**中，我们通常假设输出变量 y 和输入变量 x 之间的关系可以用一个线性方程来描述：

$$y = \beta_0 + \beta_1 x + \epsilon$$

其中：

- **β0是截距**（常数项）。
- **β1是斜率**（自变量的系数）。
- **ϵ 是误差项**，通常假设其服从均值为0的正态分布。

**最大似然估计的作用**

- **参数估计**：通过最大似然估计，我们可以找到使得观察到的数据在模型参数下最有可能发生的参数值 β0 和 β1。
- **最优性**：如果我们通过最大化似然函数得到了特定的 β0 和 β1，那么可以认为这些参数是在给定数据下的最优估计值。换句话说，这些参数使得模型最能解释观测到的数据。

**推导过程**

在进行最大似然估计时，我们通常会：

- **设定似然函数**：根据假设的误差分布（如正态分布）构建似然函数。
- **对数似然**：计算对数似然函数以简化计算。
- **求导**：对对数似然函数进行求导，并设置为零，找到参数的估计值。

**最小二乘法与最大似然估计的关系**

在线性回归中，最大似然估计的结果与最小二乘法的结果是一致的。最小二乘法通过最小化平方误差来找到参数，而最大似然估计通过最大化似然函数（在正态分布假设下）也得到了相同的参数估计。

**例子：随机点的线性回归**

**1. 数据准备**

假设我们有以下 4 个随机点 $(x, y)$：

- 点 1: $(1, 2)$
- 点 2: $(2, 3)$
- 点 3: $(3, 5)$
- 点 4: $(4, 7)$

我们可以将这个数据表示为：

- $X = [1, 2, 3, 4]$
- $Y = [2, 3, 5, 7]$

**2. 线性回归模型**

我们假设数据可以用以下线性模型表示：

$$y = \beta_0 + \beta_1 x + \epsilon$$

其中，$\epsilon$ 是误差项，通常假设其服从均值为0的正态分布。

**3. 似然函数**

在给定参数 $\beta_0$ 和 $\beta_1$ 的情况下，似然函数 $L(\beta_0, \beta_1)$ 可以表示为：

$$L(\beta_0, \beta_1) = \prod_{i=1}^{n}P(y_i\ |\ x_i, \beta_0, \beta_1)$$

**最大似然估计的作用**

- 参数估计：通过最大似然估计，我们可以找到使得观察到的数据在模型参数下最有可能发生的参数值 β0 和 β1。
- 最优性：如果我们通过最大化似然函数得到了特定的 β0 和 β1，那么可以认为这些参数是在给定数据下的最优估计值。换句话说，这些参数使得模型最能解释观测到的数据。

**推导过程**

在进行最大似然估计时，我们通常会：

- 设定似然函数：根据假设的误差分布（如正态分布）构建似然函数。
- 对数似然：计算对数似然函数以简化计算。
- 求导：对对数似然函数进行求导，并设置为零，找到参数的估计值。

**最小二乘法与最大似然估计的关系**

在线性回归中，最大似然估计的结果与最小二乘法的结果是一致的。最小二乘法通过最小化平方误差来找到参数，而最大似然估计通过最大化似然函数（在正态分布假设下）也得到了相同的参数估计。

### 4 Python代码实现

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize
# 数据点
X = np.array([1, 2, 3, 4])
Y = np.array([2, 3, 5, 7])

# 最大似然估计实现
def likelihood(params):
    beta_0, beta_1, sigma = params
    # 似然函数（对数形式）
    return -np.sum((Y - (beta_0 + beta_1 * X))**2) / (2 * sigma**2) - len(Y) * np.log(sigma)

# 初始参数猜测
initial_guess = [0, 1, 1]
# 约束条件和边界
bounds = [(None, None), (None, None), (1e-6, None)]  # sigma > 0
constraints = ({'type': 'eq', 'fun': lambda params: params[2]})  # 强制 sigma > 0

# 优化
result = minimize(lambda params: -likelihood(params), initial_guess, bounds=bounds)
beta_0_mle, beta_1_mle, sigma_mle = result.x

# 打印结果
print("MLE估计的截距（beta_0）:", beta_0_mle)
print("MLE估计的斜率（beta_1）:", beta_1_mle)

# 绘制数据点和拟合线
plt.scatter(X, Y, color='blue', label='数据点')
plt.plot(X, beta_0_mle + beta_1_mle * X, label='MLE回归线')
plt.xlabel('X')
plt.ylabel('Y')
plt.title('最大似然估计线性回归')
plt.legend()
plt.grid()
plt.show()
```

MLE估计的截距（beta_0）: 0.7999999046889545
MLE估计的斜率（beta_1）: 1.700000033182868

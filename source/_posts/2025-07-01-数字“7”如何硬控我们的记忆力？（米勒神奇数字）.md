### 今日份心理学家

{% asset_img 7.webp %}

**乔治·米勒**（George Miller），男，出生在美国西弗吉尼亚州的查尔斯顿，是普林斯顿大学的心理学教授。

他最著名的著作是 **《神奇的数字 7+/-2；我们信息加工能力的局限》**，1956年发表于《心理学评论》（The Psychological Review）。

在工作记忆模型（Working Memory Model）提出之前，美国认知心理学家乔治·米勒（George A. Miller）对 **短期记忆容量的限制** 产生了疑问。

当时，心理学家虽已将信息处理历程大致分为三类：

1. **感官记忆**（<2秒）；
2. **短时记忆**（<15秒）；
3. **长时记忆**（>15秒）；

{% asset_img 8.webp %}

米勒在1956年的一篇综述性论文中总结了大量 **短期记忆** 实验，发现无论是听觉、视觉还是语言类信息，人们 **记忆能力** 都围绕 **“7±2”** 这个范围浮动。为新兴的认知心理学提供了理论证据，也让短时记忆在现代认知心理学中受到特别重视。

### 核心观点 

我们的短期记忆容量**非常有限**，一次最多只能记住**7个“信息块”（chunk）**，上下浮动不超过2个。也就是说，大多数人只能同时记住5~9个项目，这被称为“大脑的记忆魔法数字”。

你也许会说，如果短期记忆只有这么点，我怎么能马上记住别人说了什么呀？

米勒发现，虽然短期记忆容量有限，但大脑能够将信息“组块化（chunking）”。也就是说，我们通过“打包”信息来提高效率：

记住“1-9-4-9-1-9-7-6” 很难；

但拆成 “1949 / 1976” （两年）就轻松多了。

{% asset_img 9.webp %}

大脑不是容量大，而是**善于压缩编码**，它把碎片信息整合成一块块**有意义的包装盒**，便于保存。这就解释了为什么我们能够记住像“我昨天/为了赶due/一直到1点才睡/现在困死了——”这样如此长的一句话。

### 实际应用

{% asset_img 10.webp %}

运用好chunk，可以让记忆事半功倍哦~

**Step1. 划分信息块**

**Step2. 赋予信息意义**

举个例子，让我们来看看**electroencephalogram**这个单词，它的意思是脑电图。这个单词共20个字母，但不要被它的长度吓到了！

可如果把它拆成4个单独的词根：**electro-**（电）+ **en-**（内部）+ **cephalo**（脑）+ **gram**（图表），就构成了**“记录大脑内部电活动的图像”**，即“electroencephalogram（脑电图）”。

通过这种方式拆解记忆，既能轻松记住长单词，又能掌握实用词根，遇到“**electro**therapy”（电疗）“**cephalo**metry”（头测量学）等生词时也能快速理解含义。

{% asset_img 11.webp %}

{% asset_img 12.webp %}

在生活中，“7±2”也有广泛应用。电话号码、验证码、密码长度，甚至排练台词时的断句节奏，都受这个规则影响。

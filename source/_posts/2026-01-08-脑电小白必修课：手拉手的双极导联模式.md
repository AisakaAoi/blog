上一个文章介绍了脑电采集的原理，主要是物理学原理，脑电采集就是给大脑测个“电压”，所以引出了参考电极的概念。

**记不记得参考电极可以分为物理参考和在线/离线参考？忘记了可以看一下前面一篇回顾一下。**

所以，当我们把电极贴满头皮，在屏幕上跳动的波浪线其实都是经过“二次加工”的产物。

<!--more-->

这个加工的逻辑，在脑电术语里叫**导联方式（Montage）**。

Montage记住这个英文单词，刚接触脑电的时候很容易记错。

还是拿摄影做例子吧，同样的风景，用广角镜头拍和用长焦镜头拍，效果截然不同。

{% asset_img 1.webp %}
<div align='center'>希区柯克变焦</div>

著名的电影《迷魂记》中的希区柯克变焦手法。

感觉人变得高大了吗？这个就是镜头的用法。

蒙太奇（Montage）就是脑电图的镜头。最常用的两类“镜头”是：**双极导联（Bipolar）**和**参考导联（Referential）**。

### 01 参考导联 (Referential Montage)

这是一种最直观的逻辑：选定一个公共零点，所有人都跟它比。

核心原理：通道电压 = 某电极电压 − 公共参考点电压。

就像量身高，大家都脱了鞋站在同一个地板（参考点）上。

这种参考模式的优点是，波形形状最接近真实，波幅最高的地方通常就是放电源。

做频域分析或者看波幅绝对值时，它是首选。

但是问题也存在，如果作为“地板”的公共参考点自己不干净（有噪声），那么所有通道都会“中招”，导致全图被污染。

谁有资格做这个“参考点”？没有完美的参考，只有最合适的妥协。

这里总结几个临床常用的“地板”：

- **耳垂参考 (A1/A2)**：最常用。离大脑远，也相对中性。通常把左右耳平均一下（Linked Ears），以求平衡。

{% asset_img 2.webp %}
<div align='center'>耳垂参考</div>

- **平均参考 (Average)**：把全脑所有电极电压加起来取平均。理论上最民主，但“一颗老鼠屎能坏一锅汤”。

{% asset_img 3.webp %}
<div align='center'>平均参考</div>

- **头顶参考 (Cz)**：注意！采集数据时常用它做硬件参考，但**分析时通常不建议直接用**。因为Cz就在大脑正中央，如果拿它做参考，头顶重要的脑电信号就被“做减法”抵消没啦！

{% asset_img 4.webp %}
<div align='center'>头顶参考</div>

- **鼻尖参考**：理论上很干净，但受试者容易因为呼吸、说话引入伪影，而且贴鼻尖上确实不太舒服……

最后总结下物理参考都是厂商设计的，我们基本上改不了，不过离线参考就不要纠结，对照前人的文献进行选择。

### 02 双极导联 (Bipolar Montage)

如果说参考导联是看“绝对身高”，那双极导联看的就是**“邻里差距”**。

想象所有的电极排成一列长队。双极导联不关心每个人到底有多高（绝对电压），只关心前一个人比后一个人高多少。

**我们为什么需要双极导联？**

在复杂的脑电波中，比起“谁最高”，临床医生往往更关心“异常放电是从哪里冒出来的”。双极导联不看绝对值，而是看**相邻两个电极之间的差值**。这种比较，极其善于发现局灶性的异常。

**经典阵型：纵向双极蒙太奇（Longitudinal Bipolar Montage）**

是不是听起来很好吃？因为电极连接的形状在头部两侧像两根香蕉（连接了颞叶和顶枕区域），所以又有了**“双香蕉”**这个可爱的名字。它主要由三条链组成：

{% asset_img 5.webp %}

- **外侧链（颞链）**：就像走外侧车道，Fp2→F8→T4→T6→O2。
- **内侧链（旁矢状链）**：走内环路，Fp2→F4→C4→P4→O2。
- **中线链**：Fz→Cz→Pz。

**必杀技：相位倒置 (Phase Reversal)**

这是双极导联最迷人、也是初学者最晕的地方。让我们来破解这个“针尖对麦芒”的谜题。

脑电图有个反直觉的规定——**负波向上画，正波向下画**。（历史遗留问题）

假设 F7 电极处有一个强烈的负相棘波（异常放电中心）。

- **前一个通道 (Fp1 - F7)**：因为F7是极大的负值，减去负数 = 加上正数。结果变正，波形向下走。
- **当前通道 (F7 - T3)**：F7做被减数（大负值），结果是负的。波形向上走。

{% asset_img 6.webp %}

你会看到屏幕上，相邻的两个波形一个向下、一个向上，仿佛针尖对麦芒，两个波峰互相指着对方。

只要看到这种“针尖对麦芒”，**夹在中间的那个公用电极（F7），就是异常的源头！**

这就是双极导联的威力——它能让你在乱花渐欲迷人眼的波形中，一眼“定位”病灶。

**一个小遗憾：链末端现象**

当然，这个队形也有死角。

就像排队一样，排头兵（如额极Fp1）和排尾兵（如枕区O1），因为只有一边有队友，形不成“前后夹击”，所以即便有问题也看不到相位倒置。

这时候如果只看双极导联，可能会漏诊，需要结合其他导联方式（比如**横向导联、环形导联**）综合判断。

本文提出了一种新的**多视角图卷积注意力网络（MGCANet）模型**，用于提高基于脑电图（EEG）的运动想象解码的分类准确率。该模型利用大脑区域间的拓扑关系，通过多视角特征提取和自适应权重融合，以及**引入自注意力机制，实现了更全面的信息聚合和重要特征的选择**，从而在公开数据集上（BCIC IV 2a 和 OpenBMI）取得了比现有方法更好的分类效果。

<!--more-->

### 引言

1. **BCI系统的定义和重要性**

- 脑机接口（BCI）定义为能够实现人脑与外界直接交互的系统，无需通过外围神经和肌肉。

2. **运动想象（MI）信号**

- 运动想象信号是BCI研究中最受关注的范式之一。
- 运动想象时，大脑运动皮层会产生事件相关去同步化（ERD）/事件相关同步化（ERS）现象。

3. **传统机器学习方法**

- 传统机器学习方法通常用于EEG信号的特征提取，如**滤波器组共空间模式（FBCSP）**和**子带共同空间模式（SBCSP）**。
- 这些方法依赖于人工标记进行特征选择，导致分类精度不理想。

4. **深度学习方法**

- 深度学习方法在MI解码任务中的表现优于传统机器学习方法。
- **卷积神经网络（CNN）常用于自动特征提取和分类**。

5. **图卷积网络（GCN）**

- 针对非欧几里得空间的特征提取问题，提出了基于图结构的模型。
- GCN通过局部一阶近似谱图方法，扩展了图神经网络（GNN）。

6. **注意力机制**

- 注意力机制在计算机翻译和视觉领域取得了显著进展，可以动态地为输入向量分配权重进行特征选择。
- 注意力机制也被尝试应用于运动想象解码工作。

7. **论文的主要贡献**

- **提出了一种新的多视图图卷积注意力网络（MGCANet）算法，用于解码MI-EEG信号**。
- 设计了基于物理距离和功能连接的多视图图卷积网络，以更全面地聚合信息。
- 引入自注意力机制来扩大EEG信号的接收场至全局依赖，增强重要特征的表达。

**整体架构**

- MGCANet模型包含四个主要组件：**多视图脑网络**、**空间-时间特征提取**、**特征选择**和**分类**。
  - 首先设计了多种脑连接视图，以充分反映脑区之间的拓扑关系。
  - 然后应用ResChebyNet进行空间特征提取，使用深度卷积层提取时间特征。
  - 开发了自适应加权融合（Awf）方法来自适应地结合不同视图的特征。
  - 引入自注意力机制进行特征选择。
  - 最后，将获得的特征输入分类器进行分类。

1. **多视图脑图**

- 基于神经科学研究，**构建了基于物理距离和功能连接的脑视图**。
- 描述了如何从脑图构建物理距离基础的脑视图和功能连接基础的脑视图。

2. **空间-时间特征提取**

- 使用基于谱图理论的图卷积来提取空间特征。
- **提出了基于Chebyshev多项式图卷积的方法来提取MI信号的空间特征**。
- **使用深度卷积层提取时间特征**。

{% asset_img 2.webp %}

3. **自适应加权融合（Awf）模块**

- 提出了一种自适应加权融合方法，以利用来自两种不同视图的特征的互补优势，提高解码性能。

{% asset_img 3.webp %}

4. **自注意力特征选择**

- 引入多头自注意力机制来捕捉EEG信号的全局依赖性。
- 通过自注意力机制强调可区分EEG特征的全局表达能力。

5. **分类**

- 描述了如何将提取的特征进行拼接、压缩，并输入到全连接层进行分类。

### 讨论

1. **参数选择**

- 讨论了模型参数选择对分类性能的影响。
- 展示了不同参数值（如Chebyshev多项式的阶数、图卷积层数、注意力头数和全连接层权重的最大范数）对模型性能的影响。

{% asset_img 10.webp %}

2. **自适应加权融合的消融研究**

- 对比了提出的自适应加权融合方法与其他两种特征融合方法（元素-wise加法和拼接）的性能。

{% asset_img 11.webp %}

3. **不同注意力方法的影响**

- 评估了四种不同的注意力方法（SE、ECA、SA和MHA）在两个数据集上的分类性能。
- **Squeeze-and-Excitation (SE)**：SE注意力机制通过在通道维度上学习到的权重来重新校准特征图的响应。
- **Efficient Channel Attention (ECA)**：ECA是一种轻量级的注意力机制，通过一维卷积来学习通道注意力。
- **Shuffle Attention (SA)**：SA通过打乱特征图组并在空间维度上应用注意力机制来增强网络的特征学习能力。
- **Multi-Head Attention (MHA)**：MHA是Transformer模型中使用的多头自注意力机制，能够同时在不同的表示子空间上捕捉信息。

4. **影响（缺陷）**

- **SE**：SE方法仅在通道维度上分配注意力权重，忽略了空间维度上的注意力捕捉。这可能导致模型在解码时过分依赖某些特征，从而影响性能。
- **ECA**：ECA提供了一种有效的通道注意力机制，但其性能可能不如MHA，因为它没有在多个头中并行地捕捉信息。
- **SA**：SA通过分组特征图的方式减少了通道注意力的效果，可能会影响模型的分类性能。
- **MHA**：MHA通过在时空维度上计算特征的相关性以及全局注意力信息，实现了有效的注意力权重分配，并提高了解码性能。

{% asset_img 12.webp %}

这些结果表明，在两个数据集上，使用MHA的MGCANet模型相比于其他注意力机制的模型，有着更高的分类准确率。

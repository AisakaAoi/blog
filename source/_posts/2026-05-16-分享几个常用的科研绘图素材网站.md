做科研图最烦的地方，很多时候不是不会画，而是不知道素材从哪里找。画细胞、动物实验、信号通路、实验流程图时，总要到处找图标、调颜色、改线条，最后经常变成“画图两小时，找素材五小时”。

今天这篇就整理几个我觉得比较常用的科研绘图素材网站，顺便说一下它们分别适合什么场景。

先说一句提醒：素材网站虽然方便，但正式投稿、商用或公开发布前，一定要确认授权、署名和导出格式要求。科研图好看是一回事，版权和期刊规范也不能忽略。

<!--more-->

### 01｜SciDraw：适合找基础科研 SVG 元素

网站链接：https://scidraw.io/

{% asset_img 1.webp %}

SciDraw 是一个偏科研场景的素材库，里面有很多常见的生物医学元素，比如细胞、小鼠、大鼠、鱼、鸟、人体器官、注射器、培养皿、离心管、DNA 等。它比较适合做动物实验流程图、细胞实验示意图、简单机制图和 Graphical Abstract。

我觉得 SciDraw 最大的优点是很多素材提供 SVG 矢量格式。SVG 放大后不容易糊，也方便后续放进 Illustrator、PowerPoint 或其他矢量编辑工具里继续调整。如果你只是缺几个“科研图里的基础积木”，可以先来这里找。

使用前建议点开具体素材看看作者、引用和授权信息。不同素材的使用要求可能不一样，尤其是论文投稿或商业场景，不要默认“能下载就能随便用”。

### 02｜Bioicons：简洁风的生物科研图标库

网站链接：https://bioicons.com/

{% asset_img 2.webp %}

Bioicons 是一个免费开源的生物科研图标库，整体风格比较简洁，适合做干净、统一、不花哨的科研图。它里面可以找到细胞类型、微生物、DNA、RNA、蛋白质、实验器材和分子生物学相关元素。

我个人觉得它特别适合做流程图和概念图。比如单细胞测序流程、样本处理流程、实验设计图，这些图不一定需要复杂的 3D 插画，更需要图标统一、线条清楚、信息干净。Bioicons 在这种场景下就很顺手。

不过“开源”不等于完全没有要求。不同图标可能对应不同 license，下载前最好确认是否需要 attribution。

### 03｜BioRender：成熟的科研绘图模板工具

网站链接：https://www.biorender.com/templates

{% asset_img 3.webp %}

BioRender 应该是很多科研同学都知道的工具。它的优势是图示风格成熟、模板丰富，而且非常贴近生命科学论文的表达方式。细胞生物学、免疫学、神经科学、肿瘤学、药物机制、实验流程和临床研究图示，都能找到不少模板。

如果你想快速做一张比较“期刊风”的机制图、综述图、基金标书图或教学示意图，BioRender 的模板体系确实很省时间。它尤其适合需要统一视觉风格的生物医学插图。

需要注意的是，BioRender 的导出权限、发表使用和授权范围通常和账号版本有关。正式投稿前一定要看清楚授权说明，尤其是论文发表和商业使用场景。

### 04｜Flaticon：补充通用图标很方便

网站链接：https://www.flaticon.com/search

{% asset_img 4.webp %}

Flaticon 适合找一些科研图里经常需要、但不一定属于科研专用的通用图标，比如电脑、云端、数据库、AI、医院、用户、文件、算法、统计图等。这类元素在生信流程图、AI 医学示意图、数据库平台介绍图里很常见。

比如你要画一个 AI 辅助诊断流程：患者数据、医学影像、AI 模型、风险预测、临床决策。这里除了医学元素，还会用到数据、服务器、模型、报告等通用图标，Flaticon 就很适合作为补充。

同样提醒一下，Flaticon 的素材也要看授权和署名要求，特别是公开发布和商业使用。

### 05｜IAN Symbol Libraries：适合生态和环境方向

网站链接：https://ian.umces.edu/media-library/symbols/

{% asset_img 5.webp %}

这个网站更适合生态学、环境科学、海洋、农业、地理、保护生物学和气候变化相关图。它里面有很多环境和生态相关的矢量符号，比如河流、湿地、鱼类、鸟类、森林、农业、人类活动、污染源和管理措施等。

如果你要画生态系统概念图、流域治理图、污染迁移图、碳循环或氮循环示意图，IAN Symbol Libraries 会比普通生物图标库更合适。

### 06｜NASA Scientific Visualization Studio：适合气候、遥感和空间科学

网站链接：https://svs.gsfc.nasa.gov/

如果你的方向涉及气候、遥感、天文或空间科学，可以看看 NASA Scientific Visualization Studio。它不是普通素材库，而是 NASA 基于真实科学数据制作的可视化资源库，里面有大量地球系统、海冰、海洋环流、大气、太阳活动、地球观测和空间科学相关图像与动画。

它更适合做科普、汇报、课程展示和可视化灵感参考。

### 07｜RAWGraphs：适合数据关系图

网站链接：https://www.rawgraphs.io/

{% asset_img 6.webp %}

如果你的图不是机制图，而是数据关系图，可以试试 RAWGraphs。它是一个免费开源的数据可视化工具，适合把 Excel 或 CSV 数据快速转成桑基图、弦图、树图、气泡图等更有表达力的图形。

社会科学、管理学、传播学、公共卫生、经济学和交叉学科都可能用得上。

### 08｜FigPad：从文字、草稿或参考图生成科研插图

网站链接：https://figpad.ai/

{% asset_img 7.webp %}

FigPad 和前面几个素材网站不太一样。它不是让你下载几个图标再慢慢拼，而是直接面向科研绘图场景，帮你生成完整的科研插图初稿。

如果你已经知道图里要表达什么，但不想从空白画布开始，可以用 By Text 直接输入文字描述，比如信号通路、药物作用机制、细胞互作、材料结构或实验流程。它更适合“脑子里有逻辑，但不想从零开始搭图层”的情况。

{% asset_img 8.webp %}

如果你习惯先在纸上画草稿，也可以用 By Sketch。把手绘草图上传，再补充说明，FigPad 可以根据你的构图意图生成更完整、更干净的科研图。这个功能适合那些“想法有了，但画工跟不上”的同学。

还有一种场景是风格统一。比如你要做一组机制图、流程图和模型图，希望整体配色、线条和版式一致，就可以用 By Image 参考已有图片的视觉风格，再生成同类表达。

### FigPad.ai 最实用的一点：生成后还能继续改

我觉得 FigPad 真正适合科研人的地方，不是“AI 会画图”，而是生成后还能继续编辑。科研图一定会改，如果每次改一个细节都要重新生成，效率其实并不高。

FigPad 支持导出可继续编辑的 SVG 矢量文件，也可以导出高清 PNG。也就是说，你可以先用 AI 快速生成初稿，再把 SVG 放进 Illustrator 等工具里继续精修：改文字、换颜色、移动元素、调整箭头、统一线宽，最后再按期刊要求重新排版。

### 使用建议

如果只是缺几个细胞、动物或实验器材图标，可以先看 SciDraw 和 Bioicons；如果想找成熟的生命科学模板，可以看 BioRender；如果想补充通用图标和设计元素，可以看 Flaticon；如果你的方向偏生态、环境、遥感、空间科学或数据可视化，可以看 IAN Symbol Libraries、NASA Scientific Visualization Studio 和 RAWGraphs；如果想从一句话、草稿或参考图直接生成科研插图，再继续二次编辑，可以试试 FigPad。

不同工具不是互相替代，而是适合不同阶段。前期找灵感，素材网站很有用；中期快速出图，AI 工具更省时间；后期精修投稿，矢量编辑能力很关键。

科研绘图不是把素材堆在一起。一张好的科研图，最重要的还是科学逻辑：谁作用于谁，过程从哪里开始，结果指向哪里，读者能不能一眼看懂这张图想表达什么。

希望今天这几个网站和工具，能帮你少花一点时间抠素材，多留一点时间想清楚图里的科学问题。

**最近在整理一些睡眠方面的知识，所以来一篇文章整理一下睡眠结构到睡眠分期的知识，下一篇文章我们将再次回归深度学习在脑机接口当中的应用，继续梳理模型相关的知识。**

如果只从日常体验出发，我们很容易把睡眠理解成“清醒”和“睡着”两个状态。但从 EEG、EOG、EMG 等生理信号来看，睡眠其实是一个不断变化的动态过程。

在一整晚中，大脑不会一直保持同一种状态，而是在 Wake、N1、N2、N3 和 REM 之间不断转换。不同阶段具有不同的脑电频率、波形形态、眼球运动和肌张力特征，因此睡眠分期本质上是在回答：

> 根据一段生理信号，判断此时人体正处于哪一种睡眠状态。

这一篇不只介绍“每个阶段是什么”，而是把睡眠 EEG 的知识完整串起来：

**睡眠结构 → PSG 信号 → EEG 基础节律 → Wake/N1/N2/N3/REM → Sleep Spindle、K-complex、Slow Wave → 30 秒 Epoch → Hypnogram → 睡眠周期 → 人工分期 → 自动睡眠分期 → 常见特征 → 深度学习 → 评价指标与常见混淆。**

理解这些内容以后，再去看睡眠分期论文中的 CNN、Transformer、多模态融合和跨受试者实验，就会容易很多。

### 一、先建立整体概念：睡眠到底是怎样组织起来的

{% asset_img 1.webp %}

图 1｜整夜睡眠结构图（Hypnogram）：展示一整晚 Wake、N1、N2、N3 与 REM 的周期性变化。

现代睡眠分期通常把状态划分为五类：

| 临床记号 | 本文常用写法 | 中文理解 | 所属大类 |
|---|---|---|---|
| W | Wake | 清醒 | Wake |
| N1 | N1 | 入睡／浅睡过渡 | NREM |
| N2 | N2 | 稳定浅睡眠 | NREM |
| N3 | N3 | 深睡眠／慢波睡眠 | NREM |
| R | REM | 快速眼动睡眠 | REM |

正式睡眠报告通常使用 W 和 R；本文为了便于阅读，正文与配图多写作 Wake 和 REM。两组写法分别指同一阶段。

其中：

$$\mathrm{NREM}=\mathrm{N1}+\mathrm{N2}+\mathrm{N3}$$

NREM 是 Non-Rapid Eye Movement Sleep，也就是非快速眼动睡眠；REM 是 Rapid Eye Movement Sleep，也就是快速眼动睡眠。

人入睡以后，并不是简单经历：

$$\mathrm{Wake}\rightarrow\mathrm{N1}\rightarrow\mathrm{N2}\rightarrow\mathrm{N3}$$

然后一直停留在 N3。

更真实的过程通常是：

$$\mathrm{Wake} \rightarrow \mathrm{N1} \rightarrow \mathrm{N2} \rightarrow \mathrm{N3} \rightarrow \mathrm{N2} \rightarrow \mathrm{REM}$$

随后再次进入下一轮 NREM—REM 周期。

所以整夜睡眠更像：

$$\mathrm{NREM} \rightarrow \mathrm{REM} \rightarrow \mathrm{NREM} \rightarrow \mathrm{REM} \rightarrow\cdots$$

这样的周期性变化。

通常一整晚会经历多个睡眠周期。前半夜 N3 慢波睡眠往往更多，而后半夜 REM 所占比例逐渐增加。

如果把整夜每个 30 秒 Epoch 的睡眠标签按照时间画出来，就会得到 Hypnogram（睡眠结构图）。

Hypnogram 的横轴是时间，纵轴是 Wake、REM、N1、N2、N3。

它能够非常直观地展示：

- 什么时候入睡；
- 是否频繁觉醒；
- N3 出现在什么时间；
- REM 出现了多少次；
- 不同睡眠阶段如何转换；
- 整夜睡眠结构是否连续。

### 二、为什么判断睡眠不能只看 EEG

{% asset_img 2.webp %}

图 2｜PSG 中的 EEG、EOG 与 EMG：分别反映脑活动、眼球运动和肌张力。

标准睡眠监测通常使用 PSG，也就是 Polysomnography，多导睡眠监测。

PSG 并不只记录 EEG。

根据检查目的，一套 PSG 可能同时包含：

- EEG：Electroencephalography，脑电；
- EOG：Electrooculography，眼电；
- EMG：Electromyography，肌电；
- ECG：Electrocardiography，心电；
- 鼻口气流；
- 胸腹呼吸运动；
- SpO₂；
- 体位；
- 鼾声；
- 肢体运动等。

如果只讨论**睡眠分期**，最核心的三个模态通常可以概括为：

$$\boxed{\mathrm{EEG}+\mathrm{EOG}+\mathrm{EMG}}$$

它们分别回答三个不同问题。

#### EEG：大脑现在处于什么活动状态

EEG 可以观察：

- Alpha 是否存在；
- Theta 是否增加；
- 是否出现 Sleep Spindle；
- 是否出现 K-complex；
- 是否出现大量 Slow Wave；
- EEG 是否呈现低幅混合频率活动。

因此 EEG 是睡眠分期最核心的信号。

#### EOG：眼睛现在怎样运动

EOG 对 N1 和 REM 特别有价值。

例如：

- N1 可能出现 Slow Eye Movements；
- REM 出现成串的 Rapid Eye Movements；
- Wake 中还可能看到眨眼和阅读样眼动。

因此：

$$\mathrm{Wake}\leftrightarrow\mathrm{REM}$$

仅看 EEG 有时比较困难，而加入 EOG 后通常更容易区分。

#### EMG：肌肉张力处于什么水平

下颌 EMG 能反映肌张力。

一般从 Wake 向睡眠发展时，肌张力逐渐下降；REM 时下颌肌张力通常处于整夜非常低的水平。

因此 REM 的典型组合不是只看 EEG，而是：

$$\boxed{ \mathrm{Low\ amplitude\ mixed\ frequency\ EEG} + \mathrm{Rapid\ Eye\ Movements} + \mathrm{Low\ Chin\ EMG} }$$

这也是理解多模态睡眠分期最基础的一步：

> EEG 看大脑，EOG 看眼动，EMG 看肌张力。

### 三、先认识睡眠 EEG 中最重要的几个频率成分

{% asset_img 3.webp %}

图 3｜睡眠 EEG 常见频带：Delta、Theta、Alpha、Sigma 与 Beta 的典型频率范围及波形差异。

睡眠 EEG 中经常使用 Delta、Theta、Alpha、Sigma、Beta 等频段描述不同节律。

常见划分可以整理为：

| 频带 | 常见范围 | 睡眠中的常见意义 |
|---|---|---|
| Delta | 0.5–4 Hz 左右 | N3 慢波活动明显 |
| Theta | 4–8 Hz 左右 | N1、浅睡常见 |
| Alpha | 8–13 Hz | 清醒闭眼常见 |
| Sigma | 约 11–16 Hz | Sleep Spindle 所在主要频段 |
| Beta | >13 Hz 至约 30 Hz | 清醒或较快 EEG 活动 |
| Gamma | >30 Hz | 高频活动，同时更易受 EMG 干扰 |

AASM 的睡眠分期定义中常把 Alpha 定义为 8–13 Hz，Theta 为 4–7.99 Hz，Slow Wave Activity 关注约 0.5–2 Hz 的高幅慢波。

这里的 Delta 是频带分析中常见的宽泛范围；N3 评分所用的慢波频率与幅度条件更具体，不能把“Delta 功率高”直接等同于 N3。

需要注意：

> 科研文章中的频带范围并不完全统一。

例如 Alpha 有人使用 8–12 Hz，有人使用 8–13 Hz；Sigma 和 Spindle 的频率范围也可能略有差异。

因此看论文时不能只看到“Alpha”“Sigma”这些名字，还要检查作者实际采用的频率边界。

### 四、频率、幅值和波形形态是三个不同维度

{% asset_img 4.webp %}

图 4｜频率、幅值与波形形态：睡眠分期需要同时关注节律快慢、信号强弱和特殊瞬态事件。

第一次接触睡眠 EEG 时，很容易把所有特征都理解成“频率变化”。

实际上睡眠分期至少同时关注三个层面的信息。

#### 第一层：频率

例如：

$$8\sim13\ \mathrm{Hz}$$

的 Alpha 活动。

#### 第二层：幅值

例如 N3 中的 Slow Wave 不仅慢，而且幅值较大。

#### 第三层：波形形态

例如：

- Sleep Spindle；
- K-complex；
- Vertex Sharp Wave；
- Sawtooth Wave。

这些都不仅仅是“某一个频段功率高”，而是具有特定形态和持续时间的瞬态事件。

所以真正的睡眠 EEG 分析不是：

$$\text{只看 PSD}$$

而是：

$$\boxed{ \text{频率} + \text{幅值} + \text{波形形态} + \text{时间上下文} }$$

### 五、Wake：清醒阶段到底有哪些特征

{% asset_img 5.webp %}

图 5｜Wake 的典型信号特征：闭眼 Alpha、眼动以及相对较高的肌张力。

Wake，也就是清醒。

清醒状态并不只有一种 EEG 表现。

#### 闭眼清醒

当一个人闭眼但仍然保持放松清醒状态时，枕部常出现明显的 Posterior Dominant Alpha Rhythm。

典型频率：

$$8\sim13\ \mathrm{Hz}$$

因此一段 EEG 如果出现稳定的枕部 Alpha 活动，通常支持 Wake。

#### 睁眼清醒

睁眼后 Alpha 往往减弱，EEG 变成相对：

- 低幅；
- 混合频率；
- 较快活动。

EOG 中还可能看到：

- Eye Blink；
- Reading Eye Movements；
- Rapid Eye Movements。

同时 Wake 的下颌 EMG 肌张力通常相对较高。

因此 Wake 可以从三个模态理解：

| 信号 | Wake 常见表现 |
|---|---|
| EEG | Alpha 或低幅混合频率 |
| EOG | 眨眼、阅读样眼动等 |
| EMG | 肌张力相对较高 |

这里要注意：

> Wake 并不等于“必须看到 Alpha”。

并不是所有人的 Alpha 都很明显，而且睁眼以后 Alpha 本来就会被抑制。

所以人工分期不会简单使用：

```
有 Alpha → Wake
没有 Alpha → Sleep
```

这样的单一规则。

### 六、N1：真正“睡着”的边缘状态

{% asset_img 6.webp %}

图 6｜Wake → N1：Alpha 逐渐减弱、Theta 增加，并可能出现缓慢眼球运动。

{% asset_img 7.webp %}

图 7｜N1 阶段的 Vertex Wave：一种常见于入睡早期的尖锐瞬态脑电波形。

N1 是 Wake 向睡眠过渡的阶段，也是最容易让自动分类模型困惑的阶段之一。

在 N1 中，一个典型变化就是：

$$\mathrm{Alpha}\downarrow$$

同时低幅混合频率活动增加，Theta 成分变得更加明显。

常见的 Theta 范围约为：

$$4\sim8\ \mathrm{Hz}$$

成人评分时，如果原本存在 Alpha 节律，低幅混合频率活动取代 Alpha 并占据一个 Epoch 的大部分，是支持 N1 的关键变化之一。对于本身没有明显 Alpha 的人，还需要结合背景频率变化、慢眼动和顶尖波等线索。N1 中还可能出现：

#### Slow Eye Movements

也就是缓慢滚动眼动。

EOG 在这一阶段具有很大价值。

#### Vertex Sharp Waves

Vertex Sharp Wave，也称 Vertex Wave，是 N1 中常见的一类瞬态波形。

它通常：

- 比周围背景更尖锐；
- 在中央区域较明显；
- 可以作为进入睡眠后的一个特征。

因此 N1 并不是简单一句：

> Theta 增加。

更完整的理解应该是：

$$\boxed{ \text{Alpha 减少} + \text{低幅混合频率/Theta 增加} + \text{Slow Eye Movement} + \text{可能出现 Vertex Wave} }$$

N1 为什么难分类？

因为它本质上是：

$$\mathrm{Wake}\leftrightarrow\mathrm{N1}\leftrightarrow\mathrm{N2}$$

之间的过渡状态。

它不像 N2 有非常明显的 Spindle/K-complex，也不像 N3 有大量 Slow Wave。

所以 N1 与 Wake、N2 的边界天然比较模糊。

### 七、N2：必须重点理解 Sleep Spindle 和 K-complex

{% asset_img 8.webp %}

图 8｜Sleep Spindle：N2 的重要标志性事件，常见于 11–16 Hz，其中 12–14 Hz 最常见；图中波形和时频图均为示意。

{% asset_img 9.webp %}

图 9｜K-complex：N2 中典型的大幅度孤立慢波事件。

N2 是睡眠分期中非常重要的一个阶段，也是整夜睡眠中通常占比较大的阶段。

理解 N2，最重要的是两个标志：**Sleep Spindle（睡眠纺锤波）**和 **K-complex（K 复合波）**。

#### Sleep Spindle：睡眠纺锤波

Sleep Spindle 是一段短暂的节律性活动，通常在中央导联较明显。

常见频率大约位于：

$$11\sim16\ \mathrm{Hz}$$

其中最常见的是 12–14 Hz，典型持续时间至少：

$$0.5\ \mathrm{s}$$

从波形形态上看，它通常经历“振幅增加 → 中间较大 → 振幅减小”，所以看起来像一个“纺锤”。

Sleep Spindle 与丘脑—皮层网络的同步活动有关，是 N2 非常具有代表性的 EEG 事件。

如果从信号处理角度观察，它可以表现为：

- Sigma Band 短暂能量增强；
- 时频图中约 11–16 Hz 的局部能量团；
- 带通滤波后出现明显振荡 burst。

如果使用深度学习，则 CNN 有可能直接学习这种局部波形结构。

#### K-complex：大幅度孤立慢波事件

K-complex 是另一个非常重要的 N2 标志。它通常表现为界限清楚的负向尖波，紧接一个正向成分，总持续时间至少 0.5 秒，并常在额区较明显。

从图形上看，它通常：

- 比背景 EEG 明显；
- 具有明显双相结构；
- 在额区往往比较突出。

直观来看，K-complex 更像：

> 原本比较平稳的 EEG 中突然出现一个幅度很大的慢波事件。

这也是为什么 K-complex 与普通“Delta 功率增加”不是同一个概念：前者描述瞬态形态事件，后者描述一段时间内的频率能量。

#### N2 的核心逻辑

所以 N2 可以粗略记成：

$$\boxed{ \mathrm{N2} \approx \text{低幅混合频率背景} + \text{Spindle/K-complex} }$$

但真正人工判读还要结合前后 Epoch 和持续规则。用于进入 N2 判定的 K-complex 还要区分它是否与觉醒反应相关；N2 建立后，即使后续 Epoch 暂时没有新的 Spindle 或 K-complex，也可能依据延续规则继续判为 N2。因此不能看到一次波形就机械分类。

### 八、N3：不只是“Delta 比较多”

{% asset_img 10.webp %}

图 10｜N3 慢波示意：左侧为约 1.15 Hz 的合成波形，右侧标出 0.5–2 Hz 的频段；它不代表实际患者记录。

N3 也就是 Slow-Wave Sleep，通常被理解为深睡眠。

它最典型的表现是**高幅慢波活动（High-Amplitude Slow-Wave Activity）**。

在 AASM 分期规则中，Slow Wave Activity 关注约：

$$0.5\sim2\ \mathrm{Hz}$$

的慢波，并且在规定 EEG 导联上测得的峰峰值幅度达到：

$$\gt 75\ \mu\mathrm{V}$$

在成人评分中，当这类慢波累计占一个 30 秒 Epoch 的至少 20% 时，该 Epoch 满足 N3 的核心判定条件。75 µV 阈值受导联和参考方式影响，不能脱离标准记录配置直接套用到任意单通道设备。

因为：

$$30\times20\%=6\ \mathrm{s}$$

所以从直觉上可以理解为：

> 在一个 30 秒 Epoch 中，如果有相当一部分时间都被高幅慢波占据，就非常支持 N3。

这比简单说：

> “Delta 功率高就是 N3。”

要准确得多。

因为低频功率增高也可能来自：

- 基线漂移；
- 运动伪迹；
- 电极扰动；
- 其他非睡眠相关低频变化。

所以：

$$P_{\delta}\uparrow$$

只能作为一个信号特征，而不能单独代替正式睡眠分期规则。

#### 为什么 N3 往往比 N1 更容易被模型识别

N3 的特征比较鲜明：

- 低频；
- 高幅；
- 持续时间较长；
- Slow Wave 占比明显。

因此它在特征空间中往往与 Wake、N1、REM 更容易分离。

从深度学习角度看，CNN 很容易观察到：

- 大幅度；
- 长周期；
- 连续慢波；

这些局部形态。

从频域角度看，Delta Power 也通常明显增加。

所以很多睡眠分期模型中，N3 的分类性能往往明显好于 N1。

### 九、REM：为什么它和 Wake 很容易混淆

{% asset_img 11.webp %}

图 11｜REM 的典型组合：低幅混合频率 EEG、快速眼动和低肌张力。

{% asset_img 12.webp %}

图 12｜Wake 与 REM 对比：仅看 EEG 可能相似，EOG 和 EMG 能提供关键区分信息。

REM 是 Rapid Eye Movement Sleep。

它非常特殊，因为：

> 大脑 EEG 看起来比较“清醒”，但身体肌张力却很低。

REM EEG 通常表现为：

- 低幅；
- 混合频率；
- 没有 N3 那样大量高幅慢波；
- 某些情况下可出现 Sawtooth Waves。

这使 REM 的 EEG 与 Wake 存在一定相似性。

但是 EOG 和 EMG 会提供关键线索。

#### EOG：Rapid Eye Movements

REM 阶段最有代表性的特征之一就是成串出现的快速眼球运动。

#### EMG：Low Chin Muscle Tone

REM 时下颌肌张力通常下降到整晚较低水平。

快速眼动并非每个 REM Epoch 都必须出现；已进入 REM 后，连续 Epoch 的延续判定还会结合低肌张力、EEG 背景与前后阶段。

所以 REM 最典型的组合应该一起记：**低幅混合频率 EEG + 快速眼球运动 + 低下颌肌张力**。

这也解释了为什么仅使用 EEG 与同时使用 EEG、EOG、EMG，在 REM 判别上的信息量并不一样。

只用单通道 EEG 时，Wake 和 REM 往往是重要的混淆来源之一。

### 十、把 Wake、N1、N2、N3、REM 放在一张表里

| 阶段 | EEG 与特征事件 | EOG／EMG | 常见混淆 |
|---|---|---|---|
| Wake | Alpha 或低幅混合频率；Posterior Alpha | 眨眼、阅读样眼动；肌张力较高 | REM、N1 |
| N1 | Alpha 减少，Theta／低幅混合频率增加；Vertex Wave | Slow Eye Movement；肌张力下降 | Wake、N2 |
| N2 | 低幅混合频率背景；Spindle、K-complex | 眼动较少；肌张力较低 | N1、N3 |
| N3 | 高幅低频慢波；Slow Wave | 眼动通常很少；肌张力较低 | N2 |
| REM | 低幅混合频率；可见 Sawtooth Wave | Rapid Eye Movement；肌张力很低 | Wake |

这张表适合建立整体印象，但不能当作简单的 if-else 规则。

真实 EEG 中：

- 特征可能并不典型；
- 一个 Epoch 可能位于阶段过渡处；
- 个体之间波形存在差异；
- 伪迹可能遮挡典型结构。

所以人工分期本质上仍然是在多个规则之间综合判断。

### 十一、为什么睡眠分期使用 30 秒 Epoch

{% asset_img 13.webp %}

图 13｜30 秒 Epoch：把连续 PSG 切成等长窗口并逐段赋予标签。图中 Wake→N1→N2 只是短片段示意，不代表完整睡眠周期。

睡眠分期通常把连续 PSG 划分成连续的 **30 秒 Epoch**。

假设整夜记录恰好持续 8 小时，那么共有  $8\times60\times60\div30=960$  个 Epoch。对应的睡眠阶段序列可写为：

$$Y=[y_1,y_2,\ldots,y_{960}]$$

其中每个  $y_i$  是 Wake、N1、N2、N3 或 REM 中的一个标签。如果 EEG 采样率为 100 Hz，一个 Epoch 含  $30\times100=3000$  个采样点。单通道样本的形状是  $[3000]$ ，两个通道是  $[2,3000]$ ；把 64 个双通道样本组成一批，则是  $[64,2,3000]$ 。代码中常写的  $[B,C,T]$  分别表示批量大小、通道数和采样点数，这里的  $T=3000$  来自窗口长度与采样率。

### 十二、一个 30 秒 Epoch 里面出现两个阶段怎么办

这也是理解人工睡眠分期非常关键的一点。现实睡眠并不会恰好每隔 30 秒发生一次状态变化。例如，一个 Epoch 的前 18 秒可能呈现 N2 特征、后 12 秒出现更多慢波；另一段也可能从 Wake 逐渐过渡到 N1。

人工睡眠分期会根据标准化规则为整个 30 秒 Epoch 赋予一个标签，而不是给其中每个采样点都赋一个阶段。一般先考虑哪一阶段占据 Epoch 的最大部分，同时还要服从 N2、R 等阶段的起始、延续和终止规则。因此“超过 15 秒就算哪个阶段”只能作为直觉，不能替代完整评分规则。

从机器学习角度看，一个  $X_i\in\mathbb{R}^{C\times T}$  包含 30 秒连续生理信号，但最终只对应一个阶段标签  $y_i$ 。

这其实是一种：

> 把连续睡眠过程离散化成固定时间窗口类别标签。

这也解释了为什么睡眠分期天然存在一定的标签边界模糊问题。

### 十三、为什么只看当前 Epoch 还不够

{% asset_img 14.webp %}

图 14｜单 Epoch 分类与多 Epoch 时序建模：图右使用前后片段，适用于离线分析；实时系统需要调整为只使用已获得的历史信号。

只输入当前 30 秒信号  $X_t$ ，并输出  $\hat y_t=f(X_t)$ ，称为单 Epoch 分类（Single-Epoch Classification）。

但睡眠具有明显时间结构。

例如，N1→N2→N3 可以表示睡眠逐渐加深；N2→REM 也可能出现在周期转换时。阶段转换并非固定路径，因此相邻 Epoch 能为当前片段提供额外上下文。

例如输入连续 10 个 Epoch：

$$[X_{t-4},X_{t-3},\ldots,X_t,\ldots,X_{t+5}]$$

每个 Epoch 为 30 秒，十个连续 Epoch 共覆盖  $10\times30=300$  秒，也就是 5 分钟。

这个例子使用了当前 Epoch 之后的片段，因此适合离线回看。若系统要在当前时刻实时输出，就不能访问未来 Epoch，只能使用当前和过去的信号，或明确允许等待带来的延迟。

这时模型不仅能够问：

> 当前这 30 秒 EEG 长什么样？

还能够问：

> 前面是什么阶段？现在正在往哪个阶段变化？

因此现代睡眠分期经常同时进行：

$$\boxed{ \text{Intra-Epoch Feature Learning} + \text{Inter-Epoch Sequence Modeling} }$$

前者学习一个 Epoch 内的波形特征，后者学习多个 Epoch 之间的睡眠结构。

### 十四、从算法角度看，每个睡眠阶段到底依赖什么信息

可以把五类睡眠阶段转化成机器学习视角：

#### Wake

模型可能利用：

- Alpha Power；
- 高频成分；
- EOG 眼动；
- EMG 较高肌张力。

#### N1

模型可能利用：

- Alpha 衰减；
- Theta 增强；
- Slow Eye Movements；
- Vertex Waves；
- 与 Wake/N2 的上下文转换。

#### N2

模型重点寻找：

- Sleep Spindle；
- Sigma Power；
- K-complex；
- N2 持续上下文。

#### N3

模型可能利用：

- Slow Wave；
- Delta Power；
- 高幅度；
- 较低频率；
- Slow Wave 在 Epoch 中的持续比例。

#### REM

模型可能利用：

- 低幅混合频率 EEG；
- Rapid Eye Movements；
- 低 EMG；
- 前后 Epoch 的睡眠结构。

这也解释了为什么单纯使用功率谱密度（PSD）难以覆盖全部判别信息：除了频带能量，还需要识别纺锤波等短暂事件、整合 EOG 和 EMG，并参考相邻 Epoch 的时间上下文。

### 十五、睡眠 EEG 的人工特征可以怎样系统整理

如果延续前一篇人工特征工程的思路，可以把睡眠特征分成几大类。

#### 1. 时域特征

例如：

- Mean；
- Variance；
- Standard Deviation；
- RMS；
- Peak-to-Peak；
- Zero Crossing；
- Hjorth Activity；
- Hjorth Mobility；
- Hjorth Complexity。

它们主要描述：

$$\text{幅值} + \text{波动程度} + \text{变化速度}$$

#### 2. 频域特征

睡眠中非常重要。

可以计算：

$$P_{\delta}, P_{\theta}, P_{\alpha}, P_{\sigma}, P_{\beta}$$

再进一步计算相对功率：

$$RP_{\delta} = \frac{P_{\delta}} {P_{\mathrm{total}}}$$

以及不同频带比值。

#### 3. 时频特征

使用 STFT 或 CWT：

$$x(t)\rightarrow S(f,t)$$

可以知道：

> 什么时间出现了什么频率活动。

这对 Sleep Spindle 特别重要。

如果只计算整个 30 秒的平均 Sigma Power，一个持续 1 秒的 Spindle 可能被平均掉。

而时频图中，它会表现为一个局部高能量区域。

#### 4. 非线性复杂度特征

例如：

- Sample Entropy；
- Spectral Entropy；
- Permutation Entropy；
- Fractal Dimension。

这些方法从复杂度和不规则性角度描述 EEG。

#### 5. 波形事件特征

例如：

- Spindle Count；
- Spindle Duration；
- Spindle Density；
- K-complex Count；
- Slow-Wave Count；
- Slow-Wave Duration。

这类特征更加接近睡眠医学中对典型事件的描述。

### 十六、深度学习为什么适合睡眠分期

传统机器学习通常需要：

$$\text{EEG} \rightarrow \text{人工特征} \rightarrow \text{Classifier}$$

而深度学习希望直接学习：

$$\text{Raw EEG} \rightarrow \text{Representation} \rightarrow \text{Sleep Stage}$$

例如，采样率为 100 Hz 时，CNN 可以从一个 30 秒的  $C$  通道输入  $X\in\mathbb{R}^{C\times3000}$  中学习：

- 局部慢波；
- Spindle；
- K-complex；
- 高频/低频局部模式。

进一步使用 LSTM 或 Transformer，则可以学习多个 Epoch 之间的关系。

因此一种典型睡眠模型可以写成：

$$\text{30-s EEG} \rightarrow \text{CNN Encoder} \rightarrow \text{Epoch Feature}$$

然后：

$$[\mathbf{f}_{t-4},\ldots,\mathbf{f}_{t+5}] \rightarrow \text{Transformer} \rightarrow \hat{y}_t$$

CNN 侧重回答“这一段 EEG 里面有什么”，后续序列模型则结合相邻片段，判断这段信号放在睡眠进程中的意义。这就是局部特征学习与序列建模的结合。

### 十七、多模态睡眠模型到底在融合什么

如果模型同时输入 EEG、EOG 和 EMG，获得的不只是更多通道，而是互补的生理信息：EEG 反映脑电活动，EOG 记录眼球运动，EMG 反映肌张力。

例如 REM：

- EEG 与 Wake 比较像；
- EOG 出现 Rapid Eye Movement；
- EMG 很低。

因此仅看 EEG 时，Wake 与 REM 可能混淆；加入 EOG 和 EMG 后，REM 的判别有了更多证据。

一些可穿戴设备还会加入光电容积描记（PPG）和加速度计（ACC）信号。

PPG 可以提供：

- Heart Rate；
- HRV；
- Pulse Wave Dynamics。

ACC 可以提供：

- 体动；
- 静止时间；
- 翻身；
- 姿态变化。

这些信号可用于构建多模态睡眠状态模型，但可穿戴设备的传感器组合因产品而异；仅凭 PPG 和体动估计的睡眠阶段，也不能等同于使用标准 PSG 进行的临床评分。

### 十八、为什么 N1 经常是模型最难识别的类别

很多睡眠分期结果会出现类似情况：

```
Wake   → 较好
N1     → 较差
N2     → 较好
N3     → 较好
REM    → 中等或较好
```

N1 难识别通常不是单一原因。

#### 原因 1：N1 本身就是过渡阶段

Wake→N1→N2 的变化通常是渐进的，阶段边界天然不够鲜明。

#### 原因 2：缺少非常稳定的特异性事件

N2 有睡眠纺锤波和 K 复合波，N3 有明显慢波，而 N1 缺少同样稳定、显眼的标志性事件。

#### 原因 3：样本通常较少

在许多整夜睡眠数据中，N1 所占比例相对较小。

模型训练时容易偏向样本更多的类别。

#### 原因 4：人工标注本身也存在一致性问题

当 Epoch 位于阶段交界处时，不同标注者之间可能存在一定差异。

因此，看到 N1 的 F1 分数较低时，还需要考虑它的生理特性、标签一致性和数据分布，不能只归因于模型设计。

### 十九、为什么 Wake 和 REM 容易混淆

这是另一组非常经典的混淆。

Wake 和 REM 的 EEG 都可能呈现低幅混合频率活动，因此仅凭 EEG 时容易混淆。两者在 EOG 与 EMG 上通常更容易区分：Wake 的下颏肌张力一般较高，REM 时明显降低，并可出现快速眼球运动。快速眼动并不要求每个 REM Epoch 都出现。

所以：

> Wake/REM 混淆正好说明多模态信息为什么重要。

### 二十、为什么 N2 和 N3 也会混淆

N2 向 N3 过渡时，慢波会逐渐增加。

因此某些 N2 Epoch 可能已经包含明显慢波，但还没有达到 N3 的判定条件。

因此 N2 与 N3 容易在边界 Epoch 中发生混淆。

从机器学习角度看，这也说明：

> 类别标签是离散的，但真实生理状态往往是连续变化的。

这是睡眠分期问题一个非常重要但经常被忽视的特点。

### 二十一、睡眠模型为什么不能只看 Accuracy

假设一个数据集中 N2 占很大比例。如果模型非常偏向 N2，总体准确率（Accuracy）可能仍然比较高。

因此睡眠分期一般需要同时观察：

#### Accuracy

$$ACC= \frac{\text{预测正确样本数}} {\text{总样本数}}$$

#### Precision 与 Recall

精确率（Precision）回答“预测成某一阶段的样本中，有多少真正属于该阶段”；召回率（Recall/Sensitivity）回答“真正属于该阶段的样本中，有多少被模型找到了”。

#### F1-score

$$F1= 2\cdot \frac{\mathrm{Precision}\cdot\mathrm{Recall}} {\mathrm{Precision}+\mathrm{Recall}}$$

#### Macro-F1

先分别计算 Wake、N1、N2、N3、REM 的 F1，再对五类取平均：

$$\mathrm{Macro\text{-}F1} = \frac{1}{5} \sum_{k=1}^{5}F1_k$$

因此 N1 即使样本少，也会得到与其他类别同等权重。

#### Cohen's Kappa

Kappa 会考虑随机一致性的影响：

$$\kappa= \frac{p_o-p_e} {1-p_e}$$

其中：

- $p_o$ ：实际观察到的一致率；
- $p_e$ ：随机情况下期望的一致率。

因此，报告总体准确率、Macro-F1 和 Kappa，并结合混淆矩阵，才能看清哪些阶段容易误判。

### 二十二、睡眠数据为什么特别强调跨受试者实验

如果有 20 个受试者，每个人有几百个 Epoch。

一种简单做法是：

```
所有 Epoch 混在一起
        ↓
随机划分
        ↓
Train / Test
```

这会导致：

> 同一个人的部分 Epoch 在训练集，另外部分 Epoch 在测试集。

模型可能学习：

- 这个人的 EEG 幅值习惯；
- 个体 Alpha Peak；
- 电极接触特征；
- 夜间记录特征；
- 设备差异；

然后利用这些“身份信息”帮助分类。

如果我们的目标是：

> 模型面对一个从未见过的新受试者还能不能分期？

那就应该进行 Cross-Subject Split：

```
Subject 01–16 → Train
Subject 17–18 → Validation
Subject 19–20 → Test
```

确保：

$$S_{\mathrm{train}} \cap S_{\mathrm{test}} = \varnothing$$

还可以采用留一受试者交叉验证（Leave-One-Subject-Out）：每次留出一名受试者测试，用其余受试者训练，再对每个人轮流重复。若还需选择模型和调参，验证集也必须与该次测试受试者隔离。

因此比较两篇睡眠分期论文时，不能只看：

```
Accuracy = 90%
```

而应该先问：

> 它到底是随机 Epoch 划分，还是跨受试者划分？

### 二十三、从睡眠医学知识到算法知识，可以这样串起来

整篇文章可以归纳为一条从生理现象到模型输出的链条：

1. 睡眠状态变化，伴随大脑、眼球、肌肉和自主神经活动改变。
2. EEG、EOG、EMG 等信号记录这些变化；ECG、PPG、ACC 可作为部分研究或设备的辅助信号。
3. 从信号中识别 Alpha、Theta、纺锤波、K 复合波、慢波、眼动和肌张力变化等线索。
4. 按标准规则给每个 30 秒 Epoch 标注 Wake、N1、N2、N3 或 REM。
5. 传统方法提取人工特征，深度学习模型则从信号学习表示，并结合相邻 Epoch 的上下文完成自动分期。

所以自动睡眠分期并不是一个孤立的分类任务。

它背后其实是一整条链：

$$\boxed{ \text{睡眠生理} \rightarrow \text{生理信号} \rightarrow \text{信号特征} \rightarrow \text{模式识别} }$$

### 二十四、这一篇最需要记住的几个知识点

如果第一次学习睡眠 EEG，不需要马上记住所有判读细节，但下面这些核心概念应该建立起来。

**第一，睡眠不是一个状态，而是 Wake、N1、N2、N3、REM 的动态循环。**

**第二，睡眠分期的基础不是只有 EEG，而是 EEG、EOG、EMG 的综合生理信息。**

**第三，N1 的关键是从 Wake 向睡眠过渡，Alpha 减少，Theta/低幅混合频率增加，并可能伴随慢眼动和 Vertex Wave。**

**第四，N2 最应该记住两个波形：Sleep Spindle 和 K-complex。**

**第五，N3 不能只记“Delta 高”，还要理解高幅 Slow Wave 以及其在 30 秒 Epoch 中的持续比例。**

**第六，REM 最典型的组合是低幅混合频率 EEG、快速眼动和很低的下颌肌张力。**

**第七，30 秒只是标准化睡眠分期的 Epoch 单位，真实睡眠状态本身是连续变化的。**

**第八，单个 Epoch 的波形信息和多个 Epoch 之间的时序上下文都很重要。**

**第九，N1 难分、Wake/REM 混淆、N2/N3 边界混淆都具有明确的生理原因。**

**第十，评价睡眠模型不能只看 Accuracy，还要结合 Macro-F1、Kappa、Confusion Matrix，以及最重要的数据划分方式。**

### 总结

如果只把睡眠分期看成：

$$X\rightarrow y$$

它似乎只是一个普通的五分类任务，但真正理解睡眠 EEG 后会发现，模型实际上需要同时处理：

$$\boxed{ \text{频率} + \text{幅值} + \text{波形事件} + \text{时间上下文} + \text{多模态信息} + \text{个体差异} }$$

Wake、N1、N2、N3 和 REM 并不是人为随意划分出的五个类别，而是对应着不同的大脑活动、眼球运动、肌张力以及睡眠结构。

这也是为什么做好自动睡眠分期之前，首先要理解：

> 模型究竟应该从生理信号中寻找什么。

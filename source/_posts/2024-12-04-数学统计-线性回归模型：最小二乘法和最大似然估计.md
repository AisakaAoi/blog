前面两期文章分别介绍了**最小二乘法（OLS）**和**最大似然估计(MLE)**在线性回归模型中的基本原理。本文旨在深入对比这两种算法在线性回归（LR）模型中的核心差异、表现特性以及各自的优缺点。

### 1 OLS和MLE的对比

- **最小二乘法**适用于**简单和直接的线性回归分析**，尤其在模型假设满足时表现良好。
- **最大似然估计**则更为灵活，适用于**更复杂的情况**，**包括非线性回归模型**，但需要对模型假设进行仔细检查。

#### 01 核心差异

**最小二乘法（Ordinary Least Square，OLS）**：

- 目标是**最小化残差平方和**，即最小化实际观测值与预测值之间的差异（点到直线的垂直距离）。
- 通过求解参数使得平方误差最小化。
- **假设误差项是独立同分布**，且误差项的期望为零，方差为常数（同方差性）。

**最大似然估计（Maximum Likelihood Estimation, MLE）**：

- 目标是**最大化似然函数**，即在给定参数下观察到数据的概率。
- **假设误差项服从正态分布**，通过估计参数使得观察到的数据在该模型下的概率最大。

#### 02 表现特性

**结果一致性:**

- **最大似然估计依赖于对数据的概率分布假设**。如果假设数据服从正态分布，那么最大似然估计的结果与最小二乘法在线性回归中的结果是一致的，因为正态分布下的最大似然估计等价于最小化残差平方和。
- OLS 是 MLE 在正态分布假设下的特例。

**效率:**

- 在满足正态分布假设的情况下，MLE 估计是无偏的、有效的（具有最小方差）。
- OLS 估计在相同条件下也有效，但在某些情况下，MLE 可以提供更丰富的信息（如参数的分布）

#### 03 优缺点

**最小二乘法（OLS）**

**优点：**

- **简单易懂**：理论基础简单，易于实现和解释。
- **计算效率高**：在小型数据集上计算速度快。
- 广泛应用：适用于多种线性模型，且有丰富的统计性质。

**缺点：**

- **对异常值敏感**：受极端值影响较大，可能导致估计不稳定。
- 假设限制：依赖于误差项的线性和同方差性假设，限制了其应用场景。

**最大似然估计（MLE）**

**优点：**

- **灵活性高**：可以适用于更复杂的模型和不同的分布假设。
- **提供更全面的信息**：可以得到参数的置信区间和显著性测试。
- **适用于非线性模型**：MLE 可以处理非线性回归模型，适应性强，适用于多种类型的分布。

**缺点：**

- **计算复杂性**：在某些情况下，计算似然函数和优化可能非常复杂，尤其是对于大数据集。
- **对模型假设敏感**：如果误差项不符合假设（如非正态分布），可能导致估计不准确。

**存在问题：**

联合似然估计的问题在于似然值非常小，特别是当有很多数据点时，每个数据点的似然值相乘之后得到的结果趋近于0，计算机计算起来非常复杂。因此，为了简化计算，**通常取对数得到对数似然函数： log（L）**。

#### 02 最大似然估计（MLE）

**MLE**不是直接计算数据点到直线的距离，而**是假设数据是围绕回归的直线根据某种概率分布（如正态分布）产生的**。这个假设意味着每个数据点都有一个与之对应的概率密度，而这个概率密度是由回归直线的参数（截距和斜率）以及所选择的概率分布（如正态分布）共同决定的（这个有点难理解，可以结合例子来理解）。

### 3 代码实现

将上述例子用python代码实现：

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize
import warnings
warnings.filterwarnings('ignore')
warnings.simplefilter('ignore')
%matplotlib qt
# 设置字体
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 数据点
X = np.array([1, 1.5, 3, 3.5])
Y = np.array([2, 5, 5.5, 8.5])

# 最小二乘法实现
def ols(X, Y):
    x_mean = np.mean(X)
    y_mean = np.mean(Y)
    beta_1 = np.sum((X - x_mean) * (Y - y_mean)) / np.sum((X - x_mean) ** 2)
    beta_0 = y_mean - beta_1 * x_mean
    return beta_0, beta_1
beta_0_ols, beta_1_ols = ols(X, Y)

# 最大似然估计实现
def likelihood(params):
    beta_0, beta_1, sigma = params
    # 似然函数（对数形式）
    return -np.sum((Y - (beta_0 + beta_1 * X))**2) / (2 * sigma**2) - len(Y) * np.log(sigma)
# 初始参数猜测
initial_guess = [0, 1, 1]
# 约束条件和边界
bounds = [(None, None), (None, None), (1e-6, None)]   # sigma > 0
constraints = ({'type': 'eq', 'fun': lambda params: params[2]})   # 强制 sigma > 0
# 优化
result = minimize(lambda params: -likelihood(params), initial_guess, bounds=bounds)
beta_0_mle, beta_1_mle, sigma_mle = result.x

# 打印结果
print("OLS估计的截距（beta_0）:", beta_0_ols)
print("OLS估计的斜率（beta_1）:", beta_1_ols)
print("MLE估计的截距（beta_0）:", beta_0_mle)
print("MLE估计的斜率（beta_1）:", beta_1_mle)

# 绘制数据点和拟合线
plt.scatter(X, Y, color='blue', label='数据点')
plt.plot(X, beta_0_ols + beta_1_ols * X, color='red', label='OLS回归线')
plt.plot(X, beta_0_mle + beta_1_mle * X, color='green', linestyle='--', label='MLE回归线')
plt.xlabel('X')
plt.ylabel('Y')
plt.title('最小二乘法与最大似然估计线性回归')
plt.legend()
plt.grid()
plt.show()
```

**OLS公式推导补充**

我们可以发现，OLS计算的公式跟之前计算的不太一样，是因为这里对斜率进行了更进一步的整理和简化。

**第一种OLS计算方法：**

```python
def ols(x, y):
    # 数据点的数量
    n = len(x)

    # 计算所需的求和项
    sum_x = np.sum(x)
    sum_y = np.sum(y)
    sum_x_squared = np.sum(x ** 2)
    sum_xy = np.sum(x * y)

    # 根据公式计算a
    a = (n * sum_xy - sum_x * sum_y) / (n * sum_x_squared - sum_x ** 2)
    
    # 根据公式计算b
    b = (sum_y - a * sum_x) / n
    return a, b
a, b = ols(x, y)
```

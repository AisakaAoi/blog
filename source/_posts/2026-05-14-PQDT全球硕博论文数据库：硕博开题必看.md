这期分享一个对研究生特别实用，但我发现很多学生不知道的硕博论文数据库。

**PQDT，ProQuest Dissertations & Theses Global。收录了数百万篇硕博士论文，是目前国际上覆盖范围非常广的学位论文数据库之一**

<!--more-->

我们学院明年要毕业的研究生马上要进行论文开题，我在和他们交流的时候发现一个问题。很多马上要写硕士、博士论文的同学检索了很多期刊论文，下载的硕士博士论文却远远不够。

一方面，在方法论上存在误区。在架构硕士和博士论文的时候应该更多的参考高质量的同级别论文，而不是期刊论文。另一方面，很多同学不知道在哪里下载高质量的硕博论文。

我在写博士论文的时候，发现知网上的公开硕博论文其实远远不能满足我的要求。当时我做了几个事情来扩充我的数据源，第一：借用了清北、人大等头部高校的学生账号，基本上把头部高校的内部硕博相关论文都看了一遍；第二，国家图书馆。国家图书馆也收录了大量硕博论文。我记得当时还有复印服务；第三，PQDT数据库。

### 1. PQDT 是什么？

PQDT 全称是 **ProQuest Dissertations & Theses Global**，可以理解为一个全球硕博士论文数据库。

按照 ProQuest 官方介绍，PQDT Global 目前包含 **600 万+ 条学位论文元数据记录**，其中有 **400 万+ 篇全文文档**。

中国科学院文献情报中心此前也介绍过，这个数据库收录了北美地区 90% 左右的研究生学位论文，还覆盖全球大量研究生培养机构。

所以它对研究生来说，有几个非常实际的用途：

- 看同方向博士论文的目录结构
- 学习 introduction 怎么铺垫研究问题
- 参考 literature review 的组织方式
- 看别人怎么设计研究方法和实验路线
- 顺着论文参考文献继续找核心文献

尤其是刚开始写大论文的人，不知道“整篇论文应该长什么样”，PQDT 真的很适合先看几篇样板。

### 2. 为什么写大论文前要看学位论文？

很多同学写论文时，习惯只看期刊文章。

但期刊文章通常篇幅很短，一篇文章可能只有几页到十几页，很多背景、方法细节、失败尝试、实验逻辑都被压缩掉了。

学位论文就不一样。

博士论文、硕士论文通常会把一个课题从头到尾讲完整：

第一章为什么要做这个方向。

第二章前人研究做到哪里了。

第三章具体方法怎么设计。

第四章、第五章实验结果怎么展开。

最后一章怎么总结贡献和不足。

这套结构，对正在写毕业论文的人来说，参考价值非常高。

你不是要照搬别人的内容，而是要学习它的“组织方式”。

比如你可以重点看这几个地方：

**01 | 目录**

先看目录，不要一上来就读正文。目录能最快告诉你：一个完整课题可以被拆成哪些模块。

**02 | Introduction**

看作者如何从大背景一步步收窄到具体问题。这个部分特别适合参考你自己论文第一章的写法。

**03 | Literature Review**

看它如何分类综述文献。很多时候，你缺的不是文献数量，而是不知道怎么把文献分组。

**04 | Methods**

看实验设计、数据来源、变量设置、模型选择、样本处理这些细节。期刊论文里很多方法写得太简略，学位论文通常会更完整。

**05 | References**

学位论文后面的参考文献很值得挖。尤其是同方向博士论文，参考文献里经常能找到一批基础文献和经典文献。

### 3. 如何访问 PQDT？

浏览器直接输入：

https://www.proquest.com/

如果你的学校或单位购买了 ProQuest 相关数据库，一般会自动跳转到机构登录页面，或者通过学校图书馆入口进入。

{% asset_img 1.webp %}

注意一下，PQDT 很多全文内容需要机构订阅权限。也就是说，个人账号不一定能直接下载全文，最好走学校图书馆入口。

### 4. 怎么检索更好用？

进入 PQDT 后，可以用基本检索，也可以用高级检索。

如果你只是想先随便找几篇同方向论文，可以直接在搜索框输入关键词。

比如：

```
tumor microenvironment macrophage
```

或者：

```
machine learning education
```

但如果你想找得更准，建议用高级检索。

我比较推荐这几种检索方式：

**第一种：主题词 + dissertation**

适合刚开始摸方向。

比如你想找肿瘤微环境方向的博士论文，可以搜：

```
"tumor microenvironment" AND macrophage
```

**第二种：主题词 + 方法词**

适合找实验设计或方法框架。

比如：

```
"single cell RNA sequencing" AND cancer
```

**第三种：主题词 + 学科方向**

适合找更贴近自己领域的论文。

比如：

```
"academic writing" AND graduate students
```

**第四种：限制年份**

写论文时，建议优先看近 5 年的学位论文。

不是说旧论文没价值，而是近几年的论文更容易反映当前领域的写法、研究热点和方法组合。

检索结果出来后，可以重点筛选：

- Full text / 全文
- Doctoral dissertations / 博士论文
- Publication date / 发表年份
- Subject / 学科方向
- University / 学校或机构
- Language / 语言

如果结果旁边有 PDF 标识，通常说明可以直接查看或下载全文。

### 5. 找到论文后，不要从第一页读到最后一页

很多同学看到一篇 200 页的博士论文，第一反应就是：太长了，不想看。

其实完全没必要从头读到尾。

更高效的方式，是带着目的去看。

我建议你按这个顺序快速扫一遍：

**第一步：看题目和摘要**

判断它和你的课题是不是同一类问题。

**第二步：看目录**

这是最重要的一步。你要看的不是具体内容，而是它怎么搭框架。

**第三步：看第一章**

重点看研究背景、研究问题、研究意义、创新点是怎么写出来的。

**第四步：看方法章节**

如果你的研究类型相近，这一部分可以直接帮你理解实验设计或分析流程。

**第五步：看参考文献**

把高频出现的经典文献、综述文献、方法学文献挑出来，再导入 Zotero。

这样一篇博士论文，可能30分钟就能筛出对你有用的部分。

真正值得精读的，再慢慢读。

### 6. 我最推荐的用法：拿它搭大论文框架

如果你现在正准备写毕业论文，可以这样用 PQDT：

先检索 5-10 篇与你主题接近的博士论文。

然后只看它们的目录，把章节结构整理到一个文档里。

你会很快发现，同一方向的论文往往会有一些共同结构。

比如很多实证类论文都会包含：

- Introduction
- Literature Review
- Theoretical Framework
- Methodology
- Results
- Discussion
- Conclusion

很多生物医学方向论文会包含：

- Background
- Materials and Methods
- Results
- Mechanism Exploration
- Validation
- Discussion

很多工程或计算机方向论文会包含：

- Problem Definition
- Related Work
- Model / System Design
- Experiments
- Evaluation
- Limitations

你要做的不是照搬某一篇，而是比较多篇论文后，提炼出适合自己课题的章节骨架。

这个过程特别适合开题前、写大论文初稿前、和导师讨论框架前使用。

### 7. 最后，再配合 Zotero 阅读

如果论文有 PDF，下载后建议直接导入 Zotero。

一方面，Zotero 可以帮你管理这些学位论文。

另一方面，很多 PDF 左侧会自动显示大纲，点目录就能跳到对应章节，读起来比网页里翻页方便很多。

更重要的是，你可以一边读，一边把有用的句子、框架、参考文献做笔记。

后面真正开始写自己的论文时，这些笔记会非常省时间。

### 写在最后

很多人写大论文卡住，不是因为完全不会写，而是因为一开始脑子里没有“成品感”。不知道一篇完整硕博论文应该怎么展开，也不知道自己的研究内容应该放在哪个章节里。

这个时候，与其对着空白 Word 发呆，不如先去 PQDT 找几篇同方向论文看看。不用精读。先看目录、看第一章、看方法、看参考文献。

你很快就会知道：

原来一篇大论文，是可以这样搭起来的。

如果你最近正在开题、写综述、改大论文，建议把 PQDT 收藏起来。

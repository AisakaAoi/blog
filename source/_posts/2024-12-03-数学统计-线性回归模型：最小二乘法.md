### 1 线性回归模型

**线性回归模型（Linear Regression Model，LR）**是一种统计分析方法，用于研究一个或多个自变量（解释变量）与一个因变量（被解释变量）之间的线性关系。

简单线性回归模型只有一个自变量，其一般形式为：

$$y = bx + a + \varepsilon$$

其中**y是因变量**，**x是自变量**，**a是截距**，**b是斜率**（表示x每变化一个单位，y的平均变化量），**ε是误差项**（代表了除x以外其他因素对y的影响以及测量误差等）

### 2 最小二乘法

**最小二乘法（Ordinary Least Squares , OLS）**是一种数学优化技术。它通过**最小化误差的平方和寻找数据的最佳函数匹配**。

在简单线性回归模型 y = ax+b 中，我们有一系列的观测数据点 $(x_i, y_i)$（i=1,2,…,n），**目标**是**找到一条直线，使得所有数据点到这条直线的垂直距离（误差）的平方和最小**。

**原理推导（以简单线性回归为例）：** 例子和公式来自AI

假设我们有 $n$ 个数据点 $(x_1, y_1), (x_2, y_2), \cdots, (x_n, y_n)$，线性回归方程为 $y = ax + b$。对于每个数据点 $(x_i, y_i)$，其预测值为 $\hat{y}_i = ax_i + b$，误差 $e_i = y_i - \hat{y}_i = y_i - (ax_i + b)$。

我们要最小化的目标函数是误差平方和：

$$S = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n}(y_i - ax_i - b)^2$$

为了找到使 $S$ 最小的 $a$ 和 $b$，分别对 $a$ 和 $b$ 求偏导数，并令偏导数等于 0。

**推导过程**

我们已知误差平方和 $S = \sum_{i=1}^{n}(y_i - ax_i - b)^2$。

首先对 $S$ 关于 $a$ 求偏导数：

$$\frac{\partial S}{\partial a} = -2\sum_{i=1}^{n}x_i(y_i - ax_i - b)$$

令 $\frac{\partial S}{\partial a} = 0$，则 $\sum_{i=1}^{n}x_i(y_i - ax_i - b) = 0$。

展开式子得到 $\sum_{i=1}^{n}(x_i y_i - ax_i^2 - bx_i) = 0$，进一步写成：

$$\sum_{i=1}^{n}x_i y_i - a\sum_{i=1}^{n}x_i^2 - b\sum_{i=1}^{n}x_i = 0 \tag{式1}$$

接着对 $S$ 关于 $b$ 求偏导数：

$$\frac{\partial S}{\partial b} = -2\sum_{i=1}^{n}(y_i - ax_i - b)$$

令 $\frac{\partial S}{\partial b} = 0$，则 $\sum_{i=1}^{n}(y_i - ax_i - b) = 0$，即：

$$\sum_{i=1}^{n}y_i - a\sum_{i=1}^{n}x_i - nb = 0 \tag{式2}$$

**求解 a 和 b**

由式 2 可得：

$$b = \frac{1}{n}\left(\sum_{i=1}^{n}y_i - a\sum_{i=1}^{n}x_i\right)$$

将 $b$ 的表达式代入式 1 中：

$$\sum_{i=1}^{n}x_i y_i - a\sum_{i=1}^{n}x_i^2 - \frac{1}{n}\left(\sum_{i=1}^{n}y_i - a\sum_{i=1}^{n}x_i\right)\sum_{i=1}^{n}x_i = 0$$

展开并整理可得：

$$a = \frac{n\sum_{i=1}^{n}x_i y_i - \sum_{i=1}^{n}x_i \sum_{i=1}^{n}y_i}{n\sum_{i=1}^{n}x_i^2 - \left(\sum_{i=1}^{n}x_i\right)^2}$$

再将求出的 $a$ 代入 $b = \frac{1}{n}\left(\sum_{i=1}^{n}y_i - a\sum_{i=1}^{n}x_i\right)$ 中，就可以求出 $b$ 的值。

为了更好地理解，我们举个简单的例子。假设有以下数据点 $(1,2)$、$(2,3)$、$(3,4)$：

这里 $n = 3$，$\sum_{i=1}^{3}x_i = 1 + 2 + 3 = 6$，$\sum_{i=1}^{3}y_i = 2 + 3 + 4 = 9$，$\sum_{i=1}^{3}x_i^2 = 1^2 + 2^2 + 3^2 = 14$，$\sum_{i=1}^{3}x_i y_i = 1\times2 + 2\times3 + 3\times4 = 20$。

根据公式 $a = \frac{n\sum_{i=1}^{n}x_i y_i - \sum_{i=1}^{n}x_i \sum_{i=1}^{n}y_i}{n\sum_{i=1}^{n}x_i^2 - (\sum_{i=1}^{n}x_i)^2}$，可得 $a = \frac{3\times20 - 6\times9}{3\times14 - 6^2} = 1$。

再根据 $b = \frac{1}{n}\left(\sum_{i=1}^{n}y_i - a\sum_{i=1}^{n}x_i\right)$，可得 $b = \frac{1}{3}(9 - 1\times6) = 1$。

所以，在这个简单的例子中，拟合直线为 $y = x + 1$。

### 3 python利用OLS实现LR

**根据公式手动实现上述例子：**

```python
import numpy as np
# 定义数据点
x = np.array([1, 2, 3])
y = np.array([2, 3, 4])
# 数据点的数量
n = len(x)
# 计算所需的求和项
sum_x = np.sum(x)
sum_y = np.sum(y)
sum_x_squared = np.sum(x ** 2)
sum_xy = np.sum(x * y)
# 根据公式计算a
a = (n * sum_xy - sum_x * sum_y) / (n * sum_x_squared - sum_x ** 2)
# 根据公式计算b
b = (sum_y - a * sum_x) / n
print("拟合直线的斜率a:", a)
print("拟合直线的截距b:", b)
```

**python的sklearn库实现上述例子：**

```python
from sklearn.linear_model import LinearRegression
import numpy as np
# 定义数据点
x = np.array([1, 2, 3]).reshape(-1, 1)
y = np.array([2, 3, 4])
# 创建线性回归模型对象
model = LinearRegression()
# 拟合数据
model.fit(x, y)
# 获取拟合得到的斜率a和截距b
a = model.coef_[0]
b = model.intercept_
print("拟合直线的斜率a:", a)
print("拟合直线的截距b:", b)
```

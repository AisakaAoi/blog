今天聊聊另一个一个话题：意识障碍。

如果一个重度脑损伤患者睁着眼，却几乎没有稳定的行为反应，我们最容易问的一句话往往是：**“到底哪项检查最准？”**

脑电、MRI、扩散 MRI、静息态 fMRI、FDG-PET，做完一圈之后，家属希望得到一个确定答案，临床团队也希望有一个能够压住不确定性的指标。但意识障碍这个领域最难受的地方恰恰在于：**患者没有反应，不等于患者没有残余意识；某一项检查看起来“不好”，也不等于另一项保存下来的功能没有意义。**

最近发表在Brain的一项多中心研究，把这个问题往前推了一步，我觉得还挺有意思的。

研究者整合了高密度静息 EEG、Local-Global 听觉任务 EEG、结构 MRI、扩散 MRI、静息态 fMRI 和 FDG-PET，在法国队列中分析了 326 名具有诊断数据的患者、232 名具有预后数据的患者，并在德国和意大利队列中检验了部分模态的跨中心泛化。

先把结论摆前面：**意识障碍里没有一项检查能够取代所有其他检查。** **功能性指标更擅长描述患者此刻的状态；结构和通路指标更接近“恢复的底盘”；而多模态之间不一致，本身也可能是值得记录的临床信息。**

### 01 不是“六台设备一起上”，而是六种不同的问题

这里没有假装所有模态数据都在测同一件事。

- EEG 看的是毫秒尺度上的脑活动与信息处理；
- 任务 EEG 能再追问大脑对规则、违背和刺激变化有没有层级反应；
- FDG-PET 看葡萄糖代谢，某种意义上是在看哪些脑区还维持着比较活跃的工作状态；
- 静息态 fMRI 更接近大尺度网络之间是否还在协同；
- 结构 MRI 看皮层厚度、灰质体积等解剖保存；
- dMRI 则把目光放到白质纤维和长程通路的完整性上。

把它们塞进同一张报告，不是为了凑齐一套“高端套餐”，而是因为它们回答的问题不同：

| 检查 | 更接近在看什么 | 在综合评估里的位置 |
| --- | --- | --- |
| 静息 EEG / ABCD | 背景节律、反应性、复杂度与网络组织 | 脑功能的基础状态 |
| MMN / P300 / Local-Global 任务 EEG | 听觉规则加工、变化检测与更高层级的信息处理 | 能否看到超出单纯背景的加工线索 |
| 任务 EEG / fMRI | 在合适范式下是否存在指令相关或隐匿加工 | 对行为阴性的补充证据 |
| 结构 MRI / dMRI | 皮层、深部核团与长程白质通路的保存情况 | 损伤负担与恢复底盘 |
| FDG-PET / 静息态 fMRI | 代谢水平与大尺度功能网络 | 当前功能保存的另一扇窗 |

所以，真正成熟的综合报告不该把所有检查强行压缩成一个“有意识/无意识”的开关。

它应该把证据拆开讲：**背景脑电处在什么状态，是否有层级听觉加工，任务范式有没有隐藏反应，结构通路还剩多少，代谢和网络是否支持更积极的判断，以及这些证据之间有多大一致性。**

### 02 诊断和预后，本来就不是一道题

论文里最清楚的一组结果，是单模态在“诊断当前状态”和“预测后续改善”时，排序明显变了。

在区分 UWS 和 MCS 这一类当前状态的任务里，FDG-PET 的中位平衡准确率最高，为 0.73；dMRI 和 Local-Global 任务 EEG 都在 0.69 左右，静息 EEG 为 0.66。可到了预后任务，dMRI 升到 0.74，静息态 fMRI 也仍有一定信息；PET 和两种 EEG 的表现则明显下降，静息 EEG 接近机会水平。

{% asset_img 4.webp %}
<div align='center'>图｜PET 在当前状态诊断中表现靠前，dMRI 在预后中更突出；同一模态在两类任务中的价值并不相同。来源：Manasova et al., 2026, Fig. 2。</div>

**这并不难理解。诊断更像一张“此刻的脑功能快照”：大脑有没有保留足够的代谢、网络活动和任务反应，往往更直接地决定此时能否观察到意识相关线索。预后问的却是另一件事：未来一段时间内，这个系统还有没有重建、重连和恢复的条件。白质纤维、脑干与投射通路的完整性，在这里就会变得更重要。**

换句话说，功能检查与结构检查不是谁“更高级”的问题，而是一个偏向看现在，一个偏向看底盘。把前者直接拿去替代后者，或者反过来，都会把临床问题问歪。

### 03 任务 EEG 有价值，但别把一个波峰当成判决锤

这篇研究还有一个对 EEG 从业者很有启发的细节：在跨中心验证里，Local-Global 任务 EEG 的泛化通常优于静息态 EEG。法国训练、德国测试时，Local-Global EEG 的中位平衡准确率约为 0.62，而静息 EEG 接近机会水平；在意大利队列中，Local-Global EEG 也保持了较好的表现。

国内也有一条很值得放进这段讨论的路线。2020 年，复旦大学附属华山医院神经外科团队与中科院团队合作，在 Nature Neuroscience 发表了一个基于汉语层级语言结构的床旁 EEG 范式。它不是把法国的 Local-Global 音调范式简单换成中文词汇，而是让连续语音中的单字、词组和句子分别形成 4 Hz、2 Hz 与 1 Hz 的结构节律，再观察脑电能否跟随这些语言层级。

{% asset_img 5.webp %}
<div align='center'>图｜结构化汉语刺激把单字组织为词组与句子，对应不同的语言节律。</div>

这两条路线都属于任务 EEG，却不是同一道题。Local-Global 更强调大脑是否能对局部与全局听觉规则的违背作出反应；**华山团队的范式追问的是，患者的脑活动能否从声音节拍进入词组和句子的层级解析。**前者更像检测规则更新，后者更接近观察语言处理走到了多深。原始研究中，语音追踪和脑状态动态与行为诊断、后续结局有关，但它仍是一项特定语言、特定队列和特定分析流程下的研究，不应被写成已经普及的床旁标准。

不过也要冷静一点。任务 EEG 中的诱发成分整体并不是最重要的一组特征，连接性和低频谱特征在诊断中更靠前。这不意味着 MMN、P300 或其他 ERP 没价值，而是提醒我们：**不能把“有没有一个峰”直接翻译成“患者有没有意识”或“患者一定会恢复”。**

在意识障碍报告里，MMN/P300 更适合被写成听觉层级加工的证据之一；它需要和背景脑电、反应性、复杂度、连接性、范式质量、镇静与药物背景一起解释。**一个漂亮波形不是终审判决，一份干净而可重复的多层证据链才更接近临床价值。**

### 04 多模态融合能提高表现，但不是“检查越多越接近真相”的口号

研究把不同模态逐步叠加后，诊断和预后模型的总体表现呈上升趋势；加入病因和人口学信息的扩展模型，在一些组合上进一步受益。这支持了一个朴素判断：不同模态确实带来一部分不重复的信息。

{% asset_img 6.webp %}
<div align='center'>图｜随着可用模态增加，融合模型的平衡准确率总体上升；高模态组合的样本量同时显著减少。来源：Manasova et al., 2026, Fig. 5。</div>

还有一个不能略过的细节：做到 5 种模态时，诊断组只剩 13 名患者，预后组只剩 7 名。高模态组合的曲线看起来很漂亮，却伴随着样本急剧变少和不确定性变大。把它写成“六项联查即可接近百分之百诊断”，既不符合实际，也不符合真实临床。

**多模态的价值，不是让机器给出一个更响亮的分数，而是让临床团队在证据相互补位时少漏掉一些东西。**实际落地时，还要面对费用、可及性、转运风险、镇静状态、患者耐受、采集质量和多中心标准化。很多时候，最重要的不是再加一项昂贵检查，而是先把已有检查的时间点、范式、质控和解释框架做扎实。

### 05 一份意识障碍综合报告，应该长什么样？

如果把这篇论文翻译成实际报告语言，它不该只在最后写一个 UWS 或 MCS。更有用的形式，是让每一类证据各自说清楚自己的边界：

| 报告层级 | 建议呈现的重点 |
| --- | --- |
| 行为与临床背景 | 重复 CRS-R 结果、病因、伤后时间、镇静/代谢/感染等混杂因素 |
| ABCD 与基础 EEG | 背景连续性、主导频率、反应性、睡眠结构、复杂度与网络特征 |
| MMN/P300 与任务 EEG | 听觉规则加工、诱发反应的可重复性，以及是否出现任务相关加工线索 |
| MRI / dMRI | 皮层及深部结构、白质纤维与长程通路的保存或中断 |
| PET / fMRI | 代谢保存、网络连接与行为表现是否一致 |
| 综合结论 | 当前意识状态的证据、恢复相关证据、模态不一致点、数据质量与综合置信度 |

这张表看上去没有一个特别炫的 AI 词，但它更接近多模态真正该做的事：不是替医生把人塞进一个分类框，而是把每一层脑功能证据摆在同一张桌子上，说明哪些结论比较稳，哪些还需要重复验证，哪些矛盾值得被持续追踪。

### 06 最后说白了

意识障碍不是一个适合“单指标封神”的领域。**床旁行为、EEG、任务范式、MRI、dMRI、fMRI、PET，各自都有盲区，也各自能补上别人的盲区。**

这篇Brain的多中心研究真正提醒我们的，是把“哪项检查最准”换成三个更有用的问题：**它在回答患者的当前状态，还是未来恢复？它的结果能不能跨中心、跨时间复现？当它和其他模态不一致时，这个不一致是数据问题，还是患者脑功能并不同步的信号？**答案不会因此变得更简单，但会更真实。

很多人在用 AI 做科研绘图时，第一反应是把论文摘要、研究背景、实验结果全部复制进去。

结果往往是：图看起来很炫，但信息不清楚；元素很多，但逻辑混乱；像一张宣传海报，却不像论文图。

科研绘图和普通 AI 绘图最大的不同在于：

它不是单纯追求“好看”，而是要把 **科学结构、机制路径和视觉层级** 表达清楚。

<!--more-->

一条真正好用的科研绘图提示词，通常要解决几个问题：

1. 这张图是什么类型？ 是机制图、流程图、系统架构图、材料剖面图、仪器结构图，还是期刊封面图？
2. 核心对象是什么？ 是电池结构、城市热岛、碳循环、AI 模型、仪器模块，还是实验流程？
3. 关系应该怎么表达？ 是传输、分层、循环、输入输出、因果链，还是模块连接？
4. 画面应该怎么组织？ 是从左到右、上下分层、中心放射、剖面结构，还是系统网络？
5. 视觉风格有什么限制？ 背景、配色、箭头、标签密度、是否避免海报感，都要提前说清楚。

所以，与其把一大段研究背景塞给模型，不如用“图的结构”去写提示词。

下面整理几类科研绘图中非常常见、也比较容易复用的提示词模板。你可以直接替换研究对象、结构模块和机制过程来使用。

### 01｜材料结构图：钙钛矿-硅叠层太阳能电池

这类图适合展示多层器件结构，比如太阳能电池、柔性传感器、膜材料、半导体器件、多层涂层等。

它的重点不是画一个漂亮装置，而是把 **每一层的位置、功能和界面关系** 讲清楚。

**效果图展示**

{% asset_img 1.webp %}

**不推荐这样写**

```
画一张钙钛矿太阳能电池科研图，要高级一点。
```

这句话太空，模型不知道你要画外观、结构、工作原理，还是性能对比。

**推荐提示词**

```
请生成一张适合论文发表的材料结构示意图，主题是钙钛矿-硅叠层太阳能电池。图中展示从上到下的多层堆叠结构，包括透明电极、电子传输层、钙钛矿吸收层、空穴传输层、硅底电池和背电极。请采用剖面结构图布局，清楚展示不同功能层之间的界面关系，并用简洁标签标注每一层。整体风格要求专业、清晰、适合材料科学论文配图。请使用浅色背景，采用低饱和蓝色、紫色和灰色区分不同材料层。避免夸张 3D 渲染，不要做成商业宣传海报。
```

**English Prompt**

```
Create a publication-ready scientific figure about a perovskite-silicon tandem solar cell layered stack. Show the transparent electrode, electron transport layer, perovskite absorber, hole transport layer, silicon bottom cell, and back electrode in a clean cross-section layout.Use clear labels to identify each functional layer and make the interface relationships easy to understand. Use a clean scientific illustration style with a light background, muted blue, purple, and gray tones. Avoid overly glossy 3D rendering, advertising style, and decorative background.
```

**提示词规律小总结**

材料结构图的核心是 **层级**。不要只写“画一个太阳能电池”，要写清楚：有哪些层、从上到下怎么排列、每层承担什么功能。

### 02｜传输机制图：锂离子电池截面与离子迁移

能源、材料、电化学方向，经常需要画“结构 + 传输路径”。

比如锂离子迁移、电子传导、孔道扩散、界面反应、热传输，这类图一定要把“东西怎么流动”画出来。

**效果图展示**

{% asset_img 2.webp %}

**不推荐这样写**

```
画一个锂电池结构图。
```

这样模型很可能只画一个电池外观，或者画一张很泛的科普图。

**推荐提示词**

```
请生成一张用于论文的锂离子电池截面传输机制图。图中展示正极、隔膜、电解液、负极以及集流体结构，并重点表现锂离子在充放电过程中的迁移路径、电子在外电路中的流动方向，以及电极-电解液界面处的反应区域。请采用横向剖面布局，用箭头表示锂离子迁移和电子传导方向，并在电极界面加入局部放大视图，展示离子嵌入/脱嵌过程。整体风格要求简洁、专业、适合能源材料论文。请使用白色或浅色背景，以蓝色和灰色表示电池结构，橙色或绿色突出离子传输路径。避免复杂背景和过多文字说明。
```

**English Prompt**

```
Create a publication-ready cross-sectional mechanism diagram of lithium-ion battery transport pathways. Show the cathode, separator, electrolyte, anode, and current collectors. Emphasize lithium-ion migration during charge and discharge, electron flow through the external circuit, and interfacial reactions at the electrode-electrolyte boundary.Use a horizontal cross-section layout with arrows for ion migration and electron transport. Add a zoom-in view of ion intercalation and deintercalation at the electrode interface. Use a clean scientific style with a light background and restrained colors.
```

**提示词规律小总结**

传输机制图不能只写“结构”。一定要写清楚：**传输对象是什么、从哪里到哪里、经过哪些界面、最终导致什么功能结果。**

### 03｜环境机制图：城市热岛与缓解措施

环境科学、城市规划、生态工程类图，很适合用“问题机制 + 干预措施”的方式来画。

这类图的重点不是画一个城市，而是把热源、温度梯度、绿化、水体、反照率、通风廊道这些因素之间的关系讲清楚。

**效果图展示**

{% asset_img 3.webp %}

**不推荐这样写**

```
画一张城市热岛效应图。
```

这句话容易生成一张城市风景图，而不是科研机制图。

**推荐提示词**

```
请生成一张城市热岛效应及缓解措施的科研示意图。图中展示城市中心建筑密集区、道路硬化地面、热量积累、温度升高，以及郊区或绿色区域温度较低的对比关系。请采用城市横向剖面布局，左侧展示高密度建筑和热量聚集，右侧展示绿色屋顶、城市绿地、水体、浅色铺装和通风廊道等缓解措施。请用箭头表示热量流动、空气流动和降温路径。整体风格要求清晰、专业，适合环境科学论文或政策报告。请使用浅色背景，以橙红色表示高温区域，蓝绿色表示降温和生态干预。避免卡通城市插画风，不要堆积过多装饰元素。
```

**English Prompt**

```
Create a publication-ready scientific figure about urban heat island mechanisms and mitigation interventions. Show dense buildings, impervious surfaces, heat accumulation, elevated urban temperature, and cooler suburban or green areas.Use a horizontal urban cross-section layout. Show mitigation strategies such as green roofs, urban vegetation, water bodies, high-albedo pavement, and ventilation corridors. Use arrows to indicate heat flow, airflow, and cooling pathways. Use orange-red for heat accumulation and blue-green for cooling interventions.
```

**提示词规律小总结**

环境机制图最好写成：**问题来源 + 传输路径 + 干预措施 + 结果变化**。只写一个环境现象，模型很难知道你想表达机制还是场景。

### 04｜系统循环图：全球碳循环

如果你的研究对象是一个大系统，比如碳循环、氮循环、水循环、微塑料迁移、生态系统能量流，就不要写成单向流程图。

更适合写成“系统循环图”或“通量图”。

**效果图展示**

{% asset_img 4.webp %}

**不推荐这样写**

```
画一张全球碳循环图。
```

这句话太泛，容易生成一张科普插画，缺少科研图需要的通量关系。

**推荐提示词**

```
请生成一张全球碳循环科研示意图。图中展示大气、陆地植被、土壤、海洋和人类活动之间的碳储存与碳通量关系，包括光合作用、呼吸作用、海气交换、化石燃料燃烧、土地利用变化和碳汇过程。请采用系统循环图布局，用不同方向的箭头表示碳在大气、海洋和陆地之间的交换路径。可以用箭头粗细或颜色区分主要通量和次要通量，并保持图面结构清楚。整体风格要求适合环境科学或地球系统科学论文。请使用自然科学图谱风格，背景简洁，蓝色表示海洋，绿色表示陆地生态系统，灰色或橙色表示人为排放。避免卡通地球和宣传海报风格。
```

**English Prompt**

```
Create a publication-ready scientific figure about the global carbon cycle with atmospheric, oceanic, and terrestrial carbon fluxes. Show carbon storage and exchange among the atmosphere, vegetation, soil, ocean, and human activities, including photosynthesis, respiration, air-sea exchange, fossil fuel emissions, land-use change, and carbon sinks.Use a system cycle or flux-map layout with directional arrows between reservoirs. Use arrow thickness or color to distinguish major and minor fluxes. Use a clean scientific atlas style suitable for environmental science and Earth system research.
```

**提示词规律小总结**

系统循环图的关键词是 **reservoirs + fluxes + feedback**。也就是：有哪些库、通量怎么走、有没有反馈回路。

### 05｜AI 架构图：Transformer 模型结构

计算机、AI、信息科学方向也可以用 GPTImage2 做科研图。

但这类图最怕变成“科技感背景图”。**如果你想要的是论文里的模型结构图，就一定要写 architecture、blocks、data flow，而不是只写 artificial intelligence。

**效果图展示**

{% asset_img 5.webp %}

**不推荐这样写**

```
画一张 AI 模型结构图，要有科技感。
```

这句话很容易生成发光电路板和抽象数据流，但不是可用的论文图。

**推荐提示词**

```
请生成一张 Transformer 模型架构科研示意图。图中展示输入 token embedding、positional encoding、多头自注意力模块、残差连接、层归一化、前馈神经网络、堆叠编码器模块以及最终输出表示。请采用模块化系统架构图布局，从左到右或从下到上展示数据流。每个模块用简洁矩形或功能块表示，并用箭头连接输入、注意力计算、前馈变换和输出结果。整体风格要求简洁、清晰、适合机器学习论文或学术汇报。请使用白色背景，蓝灰色为主色，少量橙色突出 attention 模块。避免赛博朋克风、发光背景和无意义的数据流装饰。
```

**English Prompt**

```
Create a publication-ready scientific figure about Transformer model architecture with attention and feed-forward blocks. Show input token embeddings, positional encoding, multi-head self-attention, residual connections, layer normalization, feed-forward neural networks, stacked encoder blocks, and final output representation.Use a modular system architecture layout with clear data flow arrows. Represent each component as a clean block. Use a minimal schematic style with a white background, blue-gray palette, and orange accents for the attention module. Avoid cyberpunk style, glowing background, and decorative data streams.
```

**提示词规律小总结**

AI 架构图不要写“科技感”。要写清楚：**输入是什么、模块有哪些、数据流怎么走、输出是什么。**

### 06｜工程系统图：IoT 监测架构

工程、传感器、智慧农业、工业互联网、环境监测方向，经常需要画“从采集到分析”的系统架构。

这类图的关键是把系统分层，而不是把所有设备堆在一起。

**效果图展示**

{% asset_img 6.webp %}

**不推荐这样写**

```
画一个物联网监测系统。
```

这句话没有说明数据从哪里来、经过哪些层、最后到哪里去。

**推荐提示词**

```
请生成一张 IoT 监测系统架构科研示意图。图中展示从边缘传感器到云端分析的完整数据链路，包括现场传感器节点、边缘网关、无线通信网络、云数据库、数据分析模型、可视化仪表盘和预警反馈。请采用分层系统架构图布局，从左到右展示数据采集、传输、存储、分析和决策输出。请用箭头表示数据流，并用回路箭头表示反馈控制。整体风格要求干净、专业，适合工程论文和项目汇报。请使用白色背景、扁平矢量风格、统一线宽和简洁标签。避免复杂 3D 场景和商业宣传图风格。
```

**English Prompt**

```
Create a publication-ready scientific figure about an IoT monitoring architecture from edge sensors to cloud analytics. Show field sensor nodes, edge gateway, wireless communication network, cloud database, analytics model, visualization dashboard, and alert feedback.Use a layered system architecture layout from left to right: data acquisition, transmission, storage, analysis, and decision output. Use arrows to show data flow and feedback control loops. Use a clean vector style with a white background and concise labels.
```

**提示词规律小总结**

系统架构图要写清楚 **层级和数据流**。比如：感知层、传输层、存储层、分析层、应用层。

### 07｜仪器结构图：三重四极杆质谱仪

如果你要介绍实验平台、仪器原理、检测系统，提示词一定要尽量具体。

仪器图不能只写仪器名字。你要告诉模型里面有哪些模块、样品怎么进入、信号怎么传递、最后怎么检测。

**效果图展示**

{% asset_img 7.webp %}

**不推荐这样写**

```
画一张质谱仪结构图。
```

这句话很容易只生成一个仪器外壳，缺少内部工作原理。

**推荐提示词**

```
请生成一张三重四极杆质谱仪的技术剖面示意图。图中展示电喷雾离子源、加热毛细管入口、离子漏斗、Q1 质量过滤器、Q2 碰撞池、Q3 质量过滤器、电子倍增检测器和真空泵系统。请用箭头展示离子从样品入口到检测器的运动轨迹，并标注不同真空区域和压力梯度。请采用技术剖面图布局，让仪器内部结构和信号传递路径清晰可见。整体风格要求专业、精确、适合分析化学论文或仪器原理介绍。请使用蓝灰色技术图风格，标签清晰，避免夸张透视和复杂背景。
```

**English Prompt**

```
Create a technical cutaway diagram of a triple quadrupole mass spectrometer. Show the electrospray ionization source, heated capillary inlet, ion funnel, Q1 mass filter, Q2 collision cell, Q3 mass filter, electron multiplier detector, and vacuum pump stages.Show the ion trajectory path from the sample inlet to the detector, and label the pressure gradient across vacuum regions. Use a precise technical cutaway layout with clear labels and arrows. Use a blue-gray scientific engineering style and avoid decorative background.
```

**提示词规律小总结**

仪器结构图的关键是：**模块名称 + 样品路径 + 信号路径 + 检测输出**。只写仪器名字，模型很难知道你要画外观还是原理。

### 08｜实验流程图：高通量筛选工作流

论文方法概览、基金技术路线、组会汇报，经常需要实验流程图。

这类图最看重的是：步骤清楚、顺序明确、一眼能看懂。

**效果图展示**

{% asset_img 8.webp %}

**不推荐这样写**

```
画一个高通量筛选流程图。
```

这句话太粗，模型不知道你要展示哪些步骤。

**推荐提示词**

```
请生成一张高通量筛选实验工作流图。图中依次展示样品准备、自动化加样、反应孵育、板式读数、数据归一化、候选 hit 筛选和二次验证。请采用从左到右的流程图布局，每一步使用独立的小场景或图标化科研元素表示，例如样品管、移液机器人、多孔板、读板仪、数据图表和验证实验。请用箭头连接所有步骤，并保持流程一目了然。整体风格要求现代、简洁、专业，适合方法学论文或项目汇报。请使用白色背景，以蓝灰色为主色，橙色用于突出候选结果。避免复杂背景，不要加入过多文字标签。
```

**English Prompt**

```
Create a publication-ready scientific workflow diagram for laboratory automation in high-throughput screening. Show sample preparation, automated liquid handling, incubation, plate reading, data normalization, hit selection, and secondary validation.Use a left-to-right workflow layout. Represent each step with a clean icon or mini-scene, such as sample tubes, liquid-handling robot, multiwell plate, plate reader, data charts, and validation assay. Connect all steps with arrows and keep the workflow easy to understand.
```

**提示词规律小总结**

流程图一定要把 **每一步** 写出来。否则模型可能只画一个仪器或一个实验台，而不是完整 workflow。

### 一个可以直接套用的科研绘图总模板

如果你不想每次都从零写，可以直接套下面这个母版。

**中文总模板**

```
请生成一张用于论文发表的【图的类型】，主题是【研究主题】。图中展示【主体对象】、【关键结构/过程 1】、【关键结构/过程 2】以及【最终结果】。请采用【构图方式】布局，例如从左到右流程图、上下分层机制图、中心场景加局部放大视图、系统架构图、循环通量图或技术剖面图。请通过箭头、局部放大视图、分层结构或模块连接来强化科学逻辑。整体风格要求简洁、专业、适合论文发表或学术汇报，具有清晰的结构层级和良好的可读性。请使用【背景要求】，以【主色】为主色，并用【强调色】突出关键事件。避免过多文字、复杂背景、夸张 3D 渲染、卡通风格和宣传海报感。
```

**English Master Prompt**

```
Create a publication-ready 【type of figure】 about 【research topic】.Show 【main object】, 【key structure/process 1】, 【key structure/process 2】, and 【final outcome】.Use a 【layout type】 composition, such as a left-to-right workflow, layered cross-section, central mechanism with zoom-in panels, system architecture, cycle/flux map, or technical cutaway.Use arrows, zoom-in views, layered structures, or modular connections to clarify the scientific logic.Use a clean, professional scientific illustration style suitable for research papers and academic slides. Keep the background simple, labels readable, and visual hierarchy clear. Avoid excessive text, decorative background, cartoon style, stock-photo look, and overly glossy CGI rendering.
```

**提示词规律小总结**

真正通用的科研绘图提示词，核心结构其实很稳定：

**图的类型 + 主体对象 + 结构/机制链条 + 构图方式 + 风格约束 + 负面限制。**

只要你按这个顺序写，提示词的稳定性会明显高于“想到什么写什么”。

### 还有一个容易被忽略的问题：生成之后怎么改？

提示词写得好，确实能让第一版图更稳定。

但科研绘图最麻烦的地方，往往不是生成，而是后续修改。

导师让你改一个箭头、换一个标签、调整配色、把中文改成英文，或者把一整张复杂机制图拆成 PPT 动画时，如果你手里只有一张 PNG，就会很痛苦。

所以我现在更推荐的工作流是：

**先用 AI 生成科研图初稿，再把它变成可以继续编辑的素材。**

我这次上面用到的案例，主要来自 FigPad Gallery。它里面有很多现成科研图和 prompt，可以直接参考结构去改自己的课题。

更重要的是，FigPad 不是只生成一张图。**它还支持导出 **PPTX / SVG / PNG**。

也就是说，你后面可以继续在 PPT 或矢量软件里改文字、改颜色、挪箭头、拆动画。

如果你只是想快速得到第一版科研图，GPTImage2 已经很好用。

但如果你希望这张图后面还能用于论文、组会、基金和答辩，建议一开始就把它当成“可编辑科研素材”来做。
